# 设备端主链交接

入口：index.html 右侧设备预览。手机侧创建即时任务，后台模拟受理后，设备显示新任务。

演示路径：接收任务 → 准备运动 → 我已入镜 → 开始倒计时 → 自动3秒倒计时 → 外部控制“模拟动作+1” → 达标结果。可暂停/结束；继续需重新确认入镜。

关闭隐私盖或离开画面停止计数；倒计时关闭隐私盖会取消倒计时。断网本地运动可继续，结束记录待同步，恢复网络后点击模拟补传。任务与记录共用 flow-core.js，设备准备状态位于 device-ui.js；刷新不自动恢复倒计时。

视觉沿用现有深色设备、学伴眼睛及圆/方屏候选；使用单强调色和简短文案，未复制参考页渐变与粒子。phone-neutral.css 未变。

设备内主要按钮可点击，画面外提供模拟入镜/离开/计数/隐私/联网等控制。未接真实摄像头或硬件。本轮未实现自主选动作、完整多项AI计划、组间休息、学校排行及姿态流程；这些按设备UE参考文档后续分轮实现，不视作本轮已完成。

验证：Node VM覆盖接收、未入镜不能倒计时、倒计时开始、离开暂停、隐私取消、断网完成保存，以及原手机结构与控制器检查。未执行真实浏览器视觉/点击验收，安全区需实机验证。
