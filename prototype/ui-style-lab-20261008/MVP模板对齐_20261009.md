# MVP 模板对齐

用户指定基准：AI运动伙伴/小程序MVP_V0.1/预览_小程序MVP.html。原文件保持不变。

本轮替换先前三套方向各自的页面结构：改用该 MVP 的统一信息架构与页面模板，三种风格作为颜色与视觉令牌变体。历史设计函数仍保留在源码中，但不再作为当前手机页面布局。此说明替代之前“保留三套不同布局”的交付描述。

- 主导航严格对齐：首页、任务、AI、成长、我的，AI 位于中央。
- 二级页：设备、动作库、记录、运动分析、姿态提醒、孩子资料。增加返回入口。
- 首页遵循原模块顺序：招呼与提示、设备、AI助手、快捷入口、今日运动、横向动作卡、任务、最近记录。
- AI恢复独立页：分析入口、七天计划、调整/发送、快捷问题与输入。
- 成长恢复学伴、概览、周图表、分析、姿态与小结；我的恢复孩子/设备及设置列表。
- 任务与设备继续接共享状态模型；动作库前两种动作可打开创建表单，未支持动作展示说明。
- 视觉改进限于令牌、排版间距、卡片层次、点击目标与键盘焦点；原模板的功能入口不以视觉探索布局替代。

新增 mvp-templates.js 保存封装的原模板函数，mvp-templates.css 保存作用域内样式。flow-ui.js 负责数据与操作适配。原 index.html 和 mobile.html 都消费这一份模板。

质量图表、星级、分钟、七天建议仍明确为示例；AI问答为固定演示回答，没有真实模型调用。成长页面的示例统计不是新增算法实现。正式接口及 PM MVP 裁剪仍需单独对齐。

Node VM 验证覆盖主链、独立手机结构、11页×3方向、五导航顺序、首页模块及AI页面。真实浏览器视觉/点击尚未验收，不能据结构检查宣称像素一致。
