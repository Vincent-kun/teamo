# 形态排布与PCB交接方案｜2026-10-08｜V0.1

> 目的：让结构与电子团队能共同定义形态、内部空间、板外形和接口，再推进PCB。本稿是供评审的排布方案，不是机械冻结或布板完成。当前已有比例与条件误差预算，尚无真实板/电池机械图，仓库本轮扫描未发现STEP/STP/DXF或KiCad PCB文件。

## 1. 本轮建议采用的形态

**供评审主方案：竖向扁胶囊，前脸局部平面，四周圆角，平底，前后分壳，可拆内支架。**保持胶囊轮廓方向，不将内部做成完整椭圆空间。前脸给屏幕与摄像头提供定位平面，内支架提供板、镜头和电池安装基准；外壳曲面负责外观，结构基准负责装配。

相邻黄金比H/W=W/D=φ继续用于主体名义外包络。57.77×35.70×93.47mm是候选A，不是PCB可用空间。曲面半径与局部平面范围必须在机械模型中确定，不能把“外尺寸减两倍壁厚”直接发给PCB团队当板尺寸。

最终外形尺寸由实际部件、装配、打印与局部截面决定；需要增大时联动三轴。验证开发板用的可拆仓可超出主体比例，明确为工程附件，不作为主体黄金比已冻结的证据。

## 2. 共用前脸与空间分区

统一坐标：X左右，Y前后（朝背部为正），Z上下（朝顶部为正）；原点取主体底面中心。后续二维图/STEP必须一致，完整机身范围为X=±W/2、Y=±D/2、Z=0～H。

| 区域 | 本次排布建议 | 对PCB/结构的约束 | 尚缺输入 |
|---|---|---|---|
| 正面上部 | 独立摄像头支架＋遮挡机构＋隐私指示 | 支架先固定光轴，不让PCB或外壳自由晃动决定镜头角度；镜头后方局部避让 | 摄像头STEP、光学中心、滑盖尺寸与ID决策 |
| 正面中部 | 屏幕模组与承托框 | 承托不直接压玻璃；完整模组、FPC与连接器占位 | 圆/方、触控、机械图与排线方向 |
| 屏幕后方中部 | 主PCB平行前脸安装（板面X-Z，厚度沿Y） | 避开上部摄像头机构；主板不能默认占满整个正面投影 | 板方案、双面器件限高、电连接与热区 |
| 后下部 | 电池作为待确认可选模块评估 | 不优先叠在摄像头后方；不靠压缩电池空间或共用热源空间解决问题 | 电池完整尺寸、保护板、引线、厂商要求 |
| 侧/背局部 | 扬声器与独立声腔、麦克风预留 | 声腔与出声孔一起布局；电池/PCB避让 | 扬声器图、声腔与固定方式 |
| 后部可用边缘 | 无线/4G天线候选区 | 净空按天线参考设计，不随意填固定距离；金属、磁吸件、电池及线材一并评审 | 天线规格、接地与净空要求 |
| 后下侧 | USB-C与调试/恢复接口 | 插拔方向及焊点受力需结构支撑，避开底面以免电源线顶起机身 | 连接器图与线头实物 |

这里“后下部电池”“侧背音频”“边缘天线”是竞争同一空间的候选位置，不代表均可同时容纳。需在共同机械模型中解决冲突，不以画多个框当作空间验证。

局部前后厚度预算：

```text
屏所在截面：前壁/承托 + 屏完整厚度 + 屏后间隙
             + PCB前侧器件高度 + PCB厚度 + 后侧器件高度
             + 绝缘/热设计/间隙 + 电池（若同截面） + 后壁

摄像头截面：镜头/模组/遮挡支架完整深度
             + 必要走线与安装空间 + 后壁
             # 主板上沿/局部切口按真实支架避让，电池优先不进入此截面
```

单板厚度不是主板占用厚度；开发板排针、插座、散热件和插入线头全部计入。尚未知的值保持空缺，不将它们当零进行整机尺寸冻结。

## 3. 三条板级路线及对应外壳

| 路线 | 排布与形态 | PCB团队现在能做什么 | 关键限制 |
|---|---|---|---|
| A：开发板验证 | 保留同一前脸/光轴支架；开发板放外置台架或可拆背仓；若可装进主体再以机械图证明 | 接口、驱动、性能、电源与外设PoC；需要转接板时按实际板与连接器定义 | 开发板仓按现成板反推尺寸，不能要求板适应最终壳；不得裁板或拆掉关键器件来假装适配 |
| B：核心板/模组＋自研载板 | 核心板放载板上或与其相连；载板负责外设接口、电源/音频等；镜头和屏继续独立定位 | 依据核心板供应商资料与结构板框设计载板，缩小比整块开发板更灵活 | 仍需核实核心板厚度、连接器和散热；载板也有打样与适配周期，并非零风险 |
| C：全定制主板 | 主PCB配合支架板框，屏/相机在前，电池与天线分区；接口位置按结构共同确定 | 架构、原理图、器件占位预布局；机械冻结后最终布局布线 | BSP/驱动、供电、射频、PCB打样与返工风险均由项目承担，不能承诺一次成功 |

建议：**当前用A验证硬件链路，同时评审B能否满足掌心包络；C仅在电子团队能力、器件与打样交期明确后推进。**这是本稿建议，不等于负责人已经批准板路线。`docs/research/bodypark-teardown/路线.md`已有“RV1106B核心板＋Carrier Board → 后续裸芯片主板”的历史建议，可作为输入；其接口引脚与Layout数字仍要按本项目实际器件复核，不能直接复制。

开发板路线下必须维护两套外形口径：

1. 产品比例样件：验证握持、前脸、稳定性及光轴，未必内置全部电子件。
2. 通电工程样机：内置现成板的加厚/加大壳，或前脸加背仓/外置台架；明确线材、供电、散热、主板位置及实际尺寸。

外置相机/屏连接必须遵守所选模组和板厂的线缆定义、长度与信号要求；不能随意加长高速FPC或将未知Pinout直接相接。

## 4. PCB机械交接包：先有共识，后冻结坐标

| 交接项 | 必须包含 | 当前状态 |
|---|---|---|
| ME-01 共用机械模型 | 外壳、支架、屏、摄像头、板、电池、天线、线材STEP；统一原点与单位mm | 未建立 |
| ME-02 板框与安装基准 | DXF/STEP板轮廓、缺口、孔坐标/孔径、板厚、结构基准面与公差 | 未冻结，不能给虚构孔坐标 |
| ME-03 双面器件限高 | 分区标明PCB正背面可放器件最大高度，屏/镜头/电池占位 | 未取得完整部件尺寸 |
| ME-04 禁布/禁铜/净空 | 镜头机构、滑盖、固定柱、连接器插拔、天线要求分别定义 | 待结构/硬件联合确认 |
| ME-05 接口与走线 | 屏/相机FPC朝向与出线口、供电/音频/电池接口、插拔空间及装配顺序 | 型号未定 |
| ME-06 热与电源 | 热源位置、导热件、与电池关系、射频供电、电源线与回流 | 待电子方案 |
| ME-07 打印校准 | 工艺、材料、方向、后处理、试片实测、间隙/补偿与版本 | 3D打印已确定，其余未知 |

“禁止放器件”“禁止走线”“禁止铺铜”不是同一规则：机械避让不自动禁止内层走线，天线净空的层别与铜要求按参考设计确定。

## 5. 今天可推进到什么程度

**第一步：结构与薛元涛评审本稿主方案及A/B/C路线。**确认摄像头位置、屏形、首版是否有电池/4G；这几项会改变板框，必须留决策记录。

**第二步：把实际部件替换进占位模型。**优先取得主板/核心板、屏、摄像头、电池机械图；对开发板额外测量排针、USB线头、散热件。没有CAD可先量实物并注明测量方法与误差，再向供应商补图。

**第三步：做粗布局联合评审。**先求所需三轴包络并验证最紧截面，同时允许PCB人员用器件占位反馈所需板面积。结构与PCB迭代，不先冻结一块过小板框再强迫电子团队塞料。

**第四步：冻结ME-02～ME-06中必要的机械接口，再开始最终PCB布局。**电子架构、接口与原理图可并行，不需等壳体打印后才开始；最终布局需要稳定的板框、限高和连接器位置。

**第五步：打印局部支架/最紧截面/配合试片。**实测修订机械交接包后再打印整壳。PCB制造前联合检查板STEP＋连接器＋外设装配，首轮只做低成本机械验证不声称已经完成整机。
