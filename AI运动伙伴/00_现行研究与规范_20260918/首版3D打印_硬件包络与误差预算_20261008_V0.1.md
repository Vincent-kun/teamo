# 首版3D打印｜硬件包络与误差预算｜2026-10-08｜V0.1

## 1. 本次变更与优先级

旧口径：候选A由原60×90正面包络面积与黄金比推得57.77×35.70×93.47mm（宽×深×高），未纳入明确工艺参数。

新输入：用户明确首版3D打印，需结合硬件及误差。继续保留相邻黄金比作为外观规则；取消“面积必须维持5400mm²”的硬约束，该面积只是候选A的起点。硬件与打印包络要求更大时，按比例放大并记录证据。

执行顺序：确认部件完整包络 → 加装配与工艺预算 → 计算三轴最低要求 → 黄金比联动求主体尺寸 → 局部曲面/截面与装配验证 → 同工艺打印校准 → 打印验证壳 → 实测修订。

每项数值标注为“供应商已核实”“历史研究”“设计预留”或“演示假设”，不得混用。标准器件、壁厚与工艺参数可以是整数；避免整数的偏好应用于公式生成的整机候选，不应人为制造小数。

## 2. 误差、间隙与补偿分别记录

| 参数 | 定义 | 本轮预算值 | 证据状态 |
|---|---|---|---|
| t | 单侧名义壁厚 | 2.00mm | 建模起始假设，非厂家最小壁厚或强度保证 |
| g | 硬件与固定槽之间每侧最小目标装配间隙 | 0.50mm | 初轮示例，后续按定位/固定方式调整；不保证居中，不直接用于光学定位 |
| uC | 打印并完成指定后处理后，整个槽/内腔跨距向内缩小的最大预算 | 0.30mm | 演示假设；不是每侧0.30，也不是所有打印机公差 |
| uP | 部件某轴最大尺寸相对名义值的增加 | 0.20mm | 仅用于屏案例演示，供应商公差未知 |
| b | CAD补偿量 | 未设置 | 必须由同设备/材料/方向/后处理试片实测形成 |

打印偏差是实物相对CAD的变化；装配间隙是主动设计的空间；补偿是依据实测对CAD的修正。三者不能互相代替。uC直接作用于最终内腔跨距，示例不再额外叠加壁厚误差或收缩率，避免重复预算；工艺变更后需要重新评估。

对单轴矩形包络的必要条件：

```text
C_nom = 外包络尺寸 - 2t         # 只作平壁/矩形包络筛查
C_min = C_nom - uC
P_max = P_nom + uP
C_min >= P_max + 2g
因此：外包络最低值 >= P_nom + uP + 2g + 2t + uC
```

圆角/扁椭圆机身扣除2t后的三轴尺寸只是内部包络的上界估计，不能据此认为有一个同尺寸矩形空腔。实际局部空间要用内表面偏置、器件位置及曲面交线检查。包络公式通过仅代表“该轴尚未排除”，不代表可装配。

## 3. 结合现有硬件的首轮筛查

历史输入来源：

- [硬件选型介绍9/24](AI运动伙伴_硬件选型工作介绍_20260924.md)：屏约48×50×2mm或61×61×3.7mm；4G候选模组尺寸。尚非当前型号机械图。
- [摄像模组技术方案§7](摄像头方案与产品形态_20260921/儿童AI运动伙伴_摄像模组技术方案_V0.1.md)：模组PCB20～25mm级、含遮挡机构建议预留40×30×30mm。此为历史安装空间建议，不能当作实际摄像头尺寸；该空间不自动适用于新ID，须重核。
- `docs/hardware/儿童AI运动陪伴机器人_MVP硬件技术需求说明书_V2.0.html`：USB-C供电必须，电池与4G未冻结；9/24研究及当前用户输入有电池/4G候选。记录需求差异，不能自行删料或认定所有候选均必选。

候选A的名义内部包络上界：53.77×31.70×89.47mm；扣除演示uC后为53.47×31.40×89.17mm。下列分析不包含曲面造成的额外损失。

| 部件/场景 | 必要条件计算 | 结论边界 |
|---|---|---|
| 48mm屏宽度案例 | 48+0.20+2×0.50+2×2.00+0.30=53.50mm外宽下限 | A的57.77mm宽通过该轴筛查；屏高度、角部、前脸开窗、FPC及固定方式未验证 |
| 61mm屏宽度案例 | 61+0.20+1.00+4.00+0.30=66.50mm外宽下限 | A宽度不满足；若选择该模组，按黄金比得到至少66.50×41.10×107.60mm的宽度驱动候选B（其余硬件仍可能要求更大） |
| 摄像头及遮挡空间 | 保留历史30mm深安装区域，再加4.00壁厚+0.30打印缩小预算，需至少34.30mm外深 | A在最有利平壁筛查下只剩1.40mm额外深度；不额外重复给历史安装预留加部件公差与装配间隙。同截面后方板/线/固定若需要更多空间，必须增深或改变布局 |
| 主板/电池/屏前后堆叠 | 当前无板与电池完整尺寸，也未定前后叠放关系 | 无法计算；不得认定35.70mm深度满足 |
| 4G与天线 | 历史模组封装不等于开发板及射频布局占用 | 需开发板/定制板图、净空、电源与布线，不按芯片小尺寸判断可装 |
| 扬声器/功放/接口/散热 | 声腔、散热件、线头和螺柱均未知 | 必须进入三维模型；电池不能以挤压或消除间隙来补空间 |

**当前结论：候选A仅可作外观比例模型；尚不具备整机容纳性确认条件。候选B只是61mm屏案例的比例放大结果，不是推荐采购/打印冻结尺寸。**

## 4. 硬件驱动的三轴联动

先依据拟定摆放位置计算局部约束与整机三轴下限，不把所有部件一律相加；同方向叠放才加尺寸，并计入实际连接器、固定与走线。

```text
φ=(1+√5)/2
W_new=max(W_A, Wmin, φ×Dmin, Hmin/φ)
D_new=W_new/φ
H_new=φ×W_new
```

Wmin/Dmin/Hmin包含硬件最大包络、必要空区、名义壁厚、装配间隙和最终打印内腔偏差预算。任何局部曲面或位置变化带来的冲突还须单独验证。未知输入保持未知，不能填零后宣称完整下限已计算。

首轮可用后附`尺寸预算计算_20261008.py`复算A及单一案例。脚本只算文档案例，没有真实部件输入，不输出整机验证通过。

## 5. 第一版打印安排

### P0：先确定加工条件并打印配合试片

向加工方取得：SLA/FDM或其他工艺、设备、材料型号、层厚/喷嘴（如适用）、摆放方向、支撑位置、清洗/固化/打磨/喷涂流程、分特征公差、交期和报价。分清“可打印最小壁厚”和功能壳体壁厚。

同工艺/同后处理先做：

- 分别打印的插入配合试片，每侧设计间隙0.15/0.25/0.35/0.45/0.55mm；每侧间隙对应跨距增量2g。该梯度为试验选择，不是统一打印规范。
- 屏安装槽局部试片：用供应商真实机械图或实物匹配；未到件只评价试片尺寸，不评价真实装配。
- 定位孔/销配合、滑盖导向与分壳接缝试片；光学定位不得沿用普通松配槽的0.50mm值。
- 50mm量级跨距试片可作为过程校准特征；同条件至少3件，记录CAD值、各轴实测、孔与槽偏差。小样不能保证整壳大跨度翘曲，整壳仍需复测。

后处理完成后测量，记录量具分辨率与重复性；分别记内外尺寸，不用层厚代表横向尺寸精度。系统偏差用于补偿，剩余散布用于误差预算；样本量不足时不作制程能力声明。

### P1：打印局部截面/可拆验证壳

确认关键机械图与工艺参数后，先验证屏槽、摄像头支架/遮挡及最紧张截面，再打印便于反复装配的分壳。第一版优先可拆固定，具体螺钉、嵌件和柱尺寸按材料、紧固件图及试片确定，不先冻结薄卡扣。

SLA须检查清洗、排液、支撑去除与固化后的实际尺寸；FDM须检查层向、接缝、翘曲与首层影响。表面处理有膜厚时单独计入配合，不按裸件尺寸验收最终喷涂件。

### P2：装配复测与记录

记录件号、CAD版本、材料批次、打印参数、处理条件、实测外形、关键内腔、装配干涉、滑盖动作、镜头视场、拆装结果。整机装入后再验证通电、发热、天线与桌面稳定性；黄金比指名义设计值，不要求实物在误差下仍精确等于φ。

## 6. 工艺依据及使用范围

- [Formlabs Form 4官方设计指南](https://formlabs.com/white-papers/form-4-design-guide/)：指南绑定指定设备、树脂与工艺条件；最小特征与尺寸精度不是同一指标。其给出的0.4mm最小间隔涉及打印过程中避免特征融合，不能直接当成我们分开打印后的配合公差。
- [Prusa官方建模指南](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)：用于核对打印方向、壁厚与配合设计。最终参数仍来自实际加工方与同工艺试片。

本稿2.00mm壁厚、0.50mm每侧间隙、0.30mm内腔预算及0.20mm硬件偏差均为透明演示假设，未从上述厂商资料转录成通用规格。
