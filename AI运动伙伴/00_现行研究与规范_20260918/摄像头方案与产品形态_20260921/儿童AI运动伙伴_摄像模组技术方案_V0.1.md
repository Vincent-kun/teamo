# 儿童 AI 运动伙伴｜摄像模组技术方案 V0.1

> 日期：2026-09-21  
> 适用阶段：摄像模组选型、RFQ、开发板 PoC、自研主板 EVT  
> 方案状态：系统需求草案；Sensor、镜头和模组供应商尚未确定  
> 产品边界：单人、室内、设备端本地动作识别；视频默认不持久化

## 1. 方案结论

采用一颗面向室内运动识别的**单目 5MP 彩色摄像模组**：

- 1/2.7～1/2.8 英寸背照式（BSI）卷帘快门（Rolling Shutter）Sensor；像素尺寸目标不小于 2.0 μm。
- 5MP RAW10 25/30 fps；通过 MIPI CSI-2 接入 RV1106B。
- 首版使用 2-Lane，主板/FPC 定义预留 4-Lane。
- 定焦镜头，DFOV 120°～130°、HFOV 105°～115°、VFOV 75°～90°。
- 目标景深 1.2～4.0 m，主要识别距离 1.5～3.0 m。
- 模组带 IR-cut；不配置红外补光、ToF、双目或电动云台。
- 物理隐私遮挡、不可由应用关闭的工作指示、Sensor 硬件 PWDN/断电同时具备。
- 5MP 仅用于采集和裁切余量；AI 推理使用 ISP 下采样后的 640×384 或 640×640 图像。

该方案不是对 BodyPark 160°镜头的复制。BodyPark 证明“5MP + MIPI + 本地 ISP/NPU”路径成立；本项目根据儿童全身动作识别，主动把镜头收敛到 120°～130°，减少画面边缘人体拉伸和关键点退化。

## 2. 使用场景和设计输入

| 项目 | 设计输入 |
|---|---|
| 用户 | 6～15 岁儿童 |
| 身高验证分组 | 115～135 cm、136～155 cm、156～175 cm |
| MVP 动作 | 开合跳、深蹲、跳绳 |
| 目标人数 | 单人；背景人员经过时主目标不得频繁切换 |
| 主要距离 | 1.5～3.0 m |
| 边界距离 | 1.2 m 提示过近；3.5 m 提示过远 |
| 机位高度 | 桌面摆放时镜头中心离地约 0.75～1.20 m |
| 环境照度 | 100～800 lux 必须稳定；50 lux 作为观察区 |
| 电网与灯光 | 中国家庭 50 Hz；覆盖 LED 灯、日光灯和窗边逆光 |
| 运行方式 | 每次 20～40 min；30 min 连续运行作为基本稳定性测试 |
| 隐私 | 本地实时处理；默认不保存视频；家长可物理关闭摄像头 |

## 3. 光学方案

### 3.1 Sensor 要求

| 参数 | P0 要求 | 说明 |
|---|---|---|
| 有效像素 | ≥5MP | 优先 2688×1944 或 2592×1944 |
| Optical format | 1/2.7～1/2.8 英寸 | 在体积、进光量和供应链间平衡 |
| 像素尺寸 | 优先 ≥2.0 μm | 有利于室内短曝光和噪声控制 |
| 工艺 | BSI | 不接受仅凭“星光级”等营销词替代原厂参数 |
| 快门 | 卷帘快门（Rolling Shutter） | MVP 可接受；通过短曝光控制运动拖影 |
| 输出 | RAW10 必须；RAW12 可选 | RAW10 作为带宽和画质的默认平衡点 |
| 帧率 | 5MP ≥25 fps；1080p 稳定 30 fps | 三动作识别下不得动态降帧 |
| HDR | P1 | 支持双曝光 HDR 更好，但不作为首版物料型号确定的前提 |
| 控制 | I²C/SCCB、RESET、PWDN、MCLK | 必须可由主控独立控制 |
| ISP 适配 | 有 RV1106/RV1106B 驱动和图像质量调试支持 | 这是物料型号确定的必要条件 |

OS05A20 级别的 5MP、1/2.7 英寸、2.0 μm、RAW10/12、MIPI Sensor 可作为能力标杆；国产 5MP AI Sensor 可作为供应链主选，但必须以目标板驱动、IQ 和连续运行实测为准。

### 3.2 镜头要求

| 参数 | 目标 |
|---|---|
| 类型 | 定焦超广角镜头，匹配 1/2.7～1/2.8 英寸 Sensor |
| DFOV | 120°～130°主测；150°仅作为对照样件 |
| HFOV | 105°～115° |
| VFOV | 75°～90° |
| 光圈 | 建议 F/2.0 级或更大通光能力，最终结合景深和边缘画质确认 |
| 工作距离 | 1.2～4.0 m |
| 对焦方式 | 工厂定焦并点胶；不使用自动对焦马达 |
| 畸变 | 供应商提供畸变曲线和标定参数；以矫正后关键点表现验收 |
| CRA | 必须与 Sensor 规格匹配 |
| IR | 配置 IR-cut；首版不配置 850/940 nm 补光 |
| 杂光 | 需提供遮光筒/镜头座方案，覆盖顶部灯光和窗边强光测试 |

不直接选择 160°的原因：视场增益集中在画面边缘，而边缘恰好是人体比例和关键点误差最严重的位置。只有当 120°/130°无法在 1.5 m 内覆盖完整人体，并且 150°样件通过边缘计数测试，才继续放宽视场。

### 3.3 光学窗口

- 前窗材料优先光学级 PC/PMMA 或玻璃，供应商需给出 400～700 nm 透过率曲线。
- 前窗不能侵入镜头最大视场；结构公差、遮挡片公差和装配偏心必须计入 ray clearance。
- 避免高亮镜面装饰环造成鬼影；镜头周围采用消光黑结构。
- 前窗与镜头间距尽量小，具体值由镜头 chief ray 和结构光路校核。
- 隐私遮挡片关闭时必须完全覆盖镜头入瞳，而不是只遮挡外观窗口的一部分。

## 4. 接口与带宽

### 4.1 带宽预算

以 2592×1944、30 fps、RAW10 为例：

```text
2592 × 1944 × 30 × 10 ≈ 1.51 Gbit/s RAW payload
```

计入 blanking、packet 和工程余量后，链路按约 1.8～2.0 Gbit/s 设计：

- 2-Lane：每 Lane 约 0.9～1.0 Gbit/s。
- RAW12 或更高帧率可能超过当前 2-Lane 目标，需要降帧或切换 4-Lane。
- 锁定 Sensor 前必须取得其实际 MIPI timing，不能只用有效像素估算。

### 4.2 FPC/连接器定义

建议采用 24-pin、0.5 mm pitch FPC，定义时保留：

- MIPI CLK±。
- MIPI DATA0±、DATA1±。
- 预留 DATA2±、DATA3±。
- CAM_AVDD、CAM_DVDD、CAM_IOVDD。
- I²C SCL/SDA。
- MCLK、RESET_N、PWDN。
- 多个 GND，优先安排在高速差分对和电源附近。

具体 pin number 在 Sensor 和模组厂确定后冻结；主板 EVT 前不得仅依照 BodyPark 未验证 pinout 画板。

### 4.3 主板原理图要求

```text
RV1106B                          CAMERA MODULE
I2C_SCL -- 22~47Ω ------------ SCL
I2C_SDA -- 22~47Ω ------------ SDA
             |-- 2.2k~4.7k pull-up to 1.8V
GPIO ------------------------- RESET_N
GPIO ------------------------- PWDN
CLK_OUT -- 22~33Ω ------------ MCLK
CSI_CLK_P/N ================== CLK_P/N
CSI_D0_P/N =================== DATA0_P/N
CSI_D1_P/N =================== DATA1_P/N
```

- I²C 上拉电压按模组 I/O 域确定，当前兼容目标为 1.8V。
- MIPI D-PHY 默认不增加串联终端，除非 Sensor reference design 明确要求。
- RESET、PWDN 有确定默认状态，避免主控启动前 Sensor 无序上电。
- FPC 连接器附近预留测试点，但高速 MIPI 线上不放长 stub 测试点。

### 4.4 PCB Layout 规则

| 项目 | 规则 |
|---|---|
| MIPI 差分阻抗 | 100 Ω ±10% |
| P/N 对内 skew | 优先 <0.15 mm，最大 <0.5 mm |
| Lane-to-lane | 建议 <5 mm |
| 过孔 | 优先 0，单线不超过 2 个，P/N 对称 |
| 参考平面 | 连续 GND，不跨 plane split |
| 隔离 | 远离 DC/DC SW node、2.4 GHz 天线、Class-D 扬声器输出 |
| ESD | 保护器件需选低电容型号，并放在连接器侧；不直接给 MIPI 增加大电容 |

## 5. 电源与时序

### 5.1 电源架构

兼容设计目标：

```text
CAM_AVDD  = 2.8V
CAM_DVDD  = 1.2V
CAM_IOVDD = 1.8V
```

最终电压、容差和上下电顺序必须服从锁定 Sensor 数据手册。上述电压不是 BodyPark 实测结果。

- CAM_AVDD 使用低噪声 LDO，不直接接高纹波 Buck。
- 每路在模组连接器和 Sensor 端按原厂建议配置去耦；典型组合为 10 μF、1 μF、0.1 μF，最终以 reference design 为准。
- 摄像头作为独立电源域，通过 load switch/LDO enable 实现真正断电。
- 电源器件需覆盖启动浪涌和至少 30% 电流余量。
- PWDN 不等于隐私关闭的唯一手段；用户关闭时优先同时关闭电源域。

### 5.2 上电时序原则

1. 电源轨按 Sensor 规定顺序建立并稳定。
2. MCLK 建立。
3. RESET_N/PWDN 按原厂延时释放。
4. I²C 探测 Sensor ID。
5. 加载 mode table 和 IQ 参数。
6. 启动 MIPI stream，检查帧同步和错误计数。

下电采用相反顺序。软件需覆盖启动失败、MIPI timeout、I²C 丢失、热重启和反复开关摄像头等异常恢复。

## 6. 功耗与热设计

### 6.1 功耗预算

| 状态/模块 | 方案预算 |
|---|---:|
| Sensor 有效采集 | 约 0.2～0.35 W |
| 模组含时钟和电源损耗 | 目标 ≤0.5 W |
| PWDN | 几 mW～几十 mW，待实测 |
| 摄像头电源域关闭 | 接近 0 W，仅保留不可避免漏电 |
| RV1106B + ISP + AI 增量 | 约 0.8～1.5 W，待目标板实测 |
| 整机运动识别状态 | 目标平均 ≤3 W，峰值按 5 W 设计 |

OS05A20 原厂公开的 Sensor active power 约 210 mW，可用于量级参考；整机预算必须加上电源转换、ISP/NPU、显示、无线和音频。

### 6.2 热设计

- Sensor 与 RV1106B、PMIC、功放保持物理距离，避免 Sensor 受热增加噪声或焦点漂移。
- SoC 通过铜皮、导热过孔、屏蔽罩或内部金属支架扩散热量。
- 模组背面不紧贴电池；镜头座附近避免高温器件。
- 30 min 连续运行后复测曝光、坏点、噪声、焦点和计数准确率。
- 外壳儿童可触表面温升目标控制在环境温度以上约 10～15℃，最终按整机安全规范验证。

## 7. 模组结构包络

### 7.1 推荐形式

量产方向采用**小型 FPC 摄像模组或 20～25 mm 小板模组**，不采用 38×38 mm 安防开发板作为产品结构基线。

| 项目 | 初步包络 |
|---|---:|
| Sensor/模组 PCB | 20×20～25×25 mm |
| 镜头外径 | 约 8～14 mm，待镜头厂确认 |
| PCB 至镜头最前端 | 约 15～25 mm |
| 摄像模组安装空间 | 建议 ≥30×30×25 mm |
| 含物理遮挡结构 | 建议预留约 40×30×30 mm |
| FPC 动态/装配弯折半径 | 建议 ≥3～5 mm，最终依 FPC 厚度确认 |

以上是结构预留值，不是量产尺寸承诺。RFQ 时必须索取 STEP、2D 公差图、镜头视锥和连接器/FPC 定义。

### 7.2 结构注意事项

- 不采用电动云台；如需调节，使用手动俯仰结构。
- 俯仰结构不能拉扯或反复折损 FPC。
- 镜头光轴相对外壳基准的装配偏差需要纳入标定；模组应有可靠定位柱/基准面。
- 遮挡滑片需要明确开/关止位、寿命和误触要求。
- 摄像头工作指示应位于镜头附近，并与 Sensor 电源/硬件 enable 关联，不能只由应用 UI 模拟。

## 8. ISP 与软件数据链路

```text
5MP RAW10 Camera
        |
        v
RV1106B MIPI CSI-2 Receiver
        |
        v
ISP：BLC / DPC / LSC / AWB / AE / NR / Distortion Correction
        |-----------------> 1920×1080 调试/预览（默认不保存）
        |-----------------> 1280×720 业务预览
        `-----------------> 640×384 或 640×640 AI 输入
                                  |
                                  v
                         Person Detection / Pose
                                  |
                                  v
                       动作状态机、计数、质量反馈
```

软件要求：

- 不把 5MP 全分辨率帧直接长期送入 NPU。
- AE 提供“运动模式”，50 Hz 灯光环境优先使用 1/100 s；光照允许时可采用更短曝光，并限制过高模拟增益。
- 防闪烁必须支持 50 Hz；60 Hz 作为兼容项。
- 畸变矫正参数按 Sensor + 镜头 + 装配组合管理，不允许不同镜头共用一套参数。
- 每套模组记录 Sensor ID、镜头料号、模组批次、IQ 版本和标定版本。
- 日志仅记录必要的状态、错误码和性能指标，不默认保存原始视频。

## 9. 隐私与安全设计

必须同时实现三层控制：

1. **物理层**：用户可见、可直接操作的镜头遮挡片。
2. **硬件层**：工作指示与 Sensor enable/电源域关联；摄像头关闭时进入 PWDN 或断电。
3. **软件层**：家长授权、撤回授权、调试录制单独授权、录制文件可删除。

验收要求：

- 遮挡关闭后无法输出可识别图像。
- 应用崩溃或主控异常不能让工作指示与实际采集状态不一致。
- 默认工作链路不落盘；工程调试模式有明显提示和自动失效机制。
- 出厂测试视频和标定数据不得包含可识别儿童影像。

## 10. 样机与验证计划

### 10.1 样件组合

首轮至少准备：

- 2 个满足 5MP/大像素要求的 Sensor 模组方案。
- 每个主模组配置约 120°、130°、150°三档镜头样件。
- 1 个有成熟 RV1106B 驱动的 4MP 模组，作为进度降级备选。

不建议一次采购大量单一镜头模组；先用小样完成光学和算法联合筛选。

### 10.2 测试矩阵

| 维度 | 测试点 |
|---|---|
| 距离 | 1.2、1.5、2.0、2.5、3.0、3.5 m |
| 身高 | 三个儿童身高分组；可先用等比例人体板完成光学测试 |
| 方位 | 正中、左右 50%、70%、85%画面位置；人体 ±20°转向 |
| 光照 | 50、100、300、800 lux；窗边逆光；LED/日光灯 |
| 动作 | 开合跳、深蹲、跳绳；宽松衣物；手脚快速运动 |
| 运行 | 冷启动、热启动、30 min连续运行、100次开关流 |
| 异常 | FPC接触异常、I²C超时、MIPI掉帧、Sensor重启 |
| 隐私 | 遮挡、PWDN、断电、指示灯一致性、默认不落盘 |

### 10.3 Go / No-Go 指标

| 指标 | Go 条件 |
|---|---|
| 完整入镜率 | 主要距离和身高组中，头、手、脚同时完整入镜 ≥95% 帧 |
| 核心关键点可用率 | 达算法置信阈值的帧占比 ≥95% |
| 边缘退化 | 人体进入画面 70%～85%区域时，计数误差相对中心增加 ≤3个百分点 |
| 三动作计数 | 每组30次：开合跳/深蹲绝对误差 ≤1；跳绳 ≤2；评测集冻结时复核 |
| 反馈延迟 | 动作完成到反馈 P95 ≤300 ms |
| 帧率 | 1080p业务流稳定30fps；掉帧率 <1% |
| 连续稳定 | 30 min无崩溃、花屏；异常恢复 ≤5 s |
| 热稳定 | 热机后画质、焦点、帧率和计数不超过规定退化范围 |
| 隐私 | 物理关闭后无可识别画面，工作指示与采集状态100%一致 |

## 11. RFQ 必填字段

向每家供应商发送同一份表格，要求完整回复：

1. Sensor 原厂、型号、生命周期、量产状态和最小起订量。
2. 有效像素、光学尺寸、像素尺寸、BSI/FSI、快门类型。
3. 5MP/1080p各模式的分辨率、帧率、RAW位宽和实际 Lane rate。
4. MIPI Lane 数、I²C地址、MCLK范围、电源轨、电流和上下电时序。
5. RV1106/RV1106B驱动版本、SDK版本、设备树和IQ文件交付范围。
6. 镜头 DFOV/HFOV/VFOV、焦距、F/#、TTL、畸变曲线、CRA和MTF曲线。
7. 120°/130°/150°镜头样件可供性，以及能否在同一Sensor模组上互换。
8. 模组尺寸、公差、STEP、2D图、FPC/连接器定义和可靠性数据。
9. Active/PWDN/断电功耗及测试条件。
10. 单价阶梯：样件、100、1k、10k；NRE、交期、产能和停产通知周期。
11. IQ调试支持内容、驻场/远程支持方式、问题响应时间。
12. 是否可提供标定参数、批次追溯和出厂画质测试。

任何不愿提供实际 Lane rate、驱动/SDK 版本、镜头畸变曲线或模组 3D 图的候选，不进入首轮主选。

## 12. 冻结节点

### 系统需求评审（SRR）

- 冻结 5MP、单目、120°～130°主测、2-Lane起步/4-Lane预留。
- 冻结使用距离、身高分组、光照和三动作验收口径。

### 初步设计评审（PDR）

- 至少两家供应商完成 RFQ 回复。
- 拿到驱动、IQ交付承诺、样件和完整结构资料。

### 关键设计评审（CDR）

- 在同一块 RV1106B 目标板完成全部 Go / No-Go 测试。
- 通过算法、硬件、结构、供应链联合评审。

### 测试准备评审（TRR）

- 冻结 24-pin FPC pinout、电源轨、时序和 MIPI timing。
- 冻结镜头视锥、模组 STEP 和装配基准。
- 完成 SI/PI、热和隐私设计检查。

## 13. 当前风险和降级策略

| 风险 | 触发条件 | 降级策略 |
|---|---|---|
| 5MP Sensor 无成熟 RV1106B 驱动 | 样件到货仍无法稳定出图 | 使用成熟4MP模组先完成算法PoC，主板保持5MP兼容 |
| 130°仍无法近距离完整入镜 | 1.5 m完整入镜率不达标 | 比较150°样件；先优化机位高度和俯仰，再放宽FOV |
| 超广角边缘关键点退化 | 边缘计数误差增加>3个百分点 | 收窄FOV、加强标定或在UI中限定有效运动区域 |
| 室内拖影严重 | 100 lux下关键点连续丢失 | 运动AE限制曝光，优化增益/降噪；必要时重新评估大像素Sensor |
| 功耗/温升超标 | 整机平均>3W或热机画质退化 | 降低非必要预览、屏幕亮度和无线占空比；Sensor无人时断电 |
| 模组体积超结构包络 | 镜头/FPC干涉或头部过厚 | 改用定制FPC小模组，取消电动机构，不优先牺牲Sensor尺寸 |

## 14. 可直接用于评审的结论

> MVP 摄像模组采用单目 5MP 背照式（BSI）卷帘快门（Rolling Shutter）方案，Sensor 目标为 1/2.7～1/2.8 英寸、约 2.0 μm像素，输出 RAW10 5MP 25/30fps，经 MIPI CSI-2 2-Lane 接入 RV1106B；主板和24-pin FPC预留4-Lane。镜头首选120°～130°对角视场、定焦、IR-cut，主要覆盖1.5～3.0m单人全身运动。160°不作为默认方案，仅作为近距离入镜对照。模组连续功耗目标≤0.5W，模组PCB目标≤25×25mm，包含物理遮挡机构的安装空间预留约40×30×30mm。Sensor和镜头具体物料型号必须在目标板完成驱动、图像质量调试、三动作、边缘、低照、热稳定及隐私测试后确定。
