# 现行研究与规范

本目录存放 2026-09-18 起形成的竞品研究、产品定义与边界规范，与上级目录中的既有产品资料和旧版竞品稿隔离。

## 文件与用途

1. `儿童AI运动陪伴机器人_产品定义定位与边界规范_V1.0.md`  
   当前产品定位、初心、价值排序、社区/内容/商业边界与功能准入规则。
2. `竞品分析输出规范_V3.0_决策版.md`  
   后续所有竞品调研的现行输出标准。
3. `竞品分析方法论与竞品池_研究底稿_V1.0_20260918.md`  
   支撑 V3.0 的方法论、官方来源和竞品池核验资料。
4. `竞品软件体验观察记录_V1.0_20260918.md`  
   用户对 Keep、betterWE 星球、BodyPark、天天跳绳和满分运动的个人体验记录。

## 权威顺序

出现冲突时按以下顺序处理：

1. 本目录中的产品定义与边界规范；
2. 本目录中的竞品分析输出规范 V3.0；
3. 本目录中的研究底稿与体验记录；
4. 上级目录既有 PRD、商业画布和功能大纲；
5. 旧版竞品格式、旧调研稿和旧分析报告。

这里的“权威顺序”只用于本轮竞品研究与产品定位工作，不表示现有 PRD 已被自动修改或废弃。若新规范与现有 PRD 冲突，必须单独列出并经过产品评审，不能静默覆盖。

## 隔离规则

- 上级目录文件视为“既有资料/历史输入”，本轮不直接改写。
- 新的竞品报告、体验记录和定位修订默认写入本目录。
- 旧版 `竞品分析格式规范_V1.0.md`、`竞品分析输出规范_V2.0_研究版.md` 仅供版本追溯，不再作为新报告模板。
- 旧报告中的价格、参数、销量、用户规模和结论不得直接复制到新报告，必须重新核实。
- 新结论若要进入 PRD、商业画布或功能大纲，应通过显式的“旧口径—新证据—建议修改”变更单处理。
