# 儿童 AI 运动陪伴机器人 · 产品定义、定位与边界规范 V1.0

> 日期：2026-09-18  
> 状态：产品评审基线  
> 依据：现有商业画布、功能大纲、PRD、MVP 与版本演进说明，以及本轮 Keep、betterWE 星球、BodyPark、天天跳绳、满分运动体验反馈  
> 作用：当功能、内容、社区或商业化方案发生冲突时，以本文判断它是否符合产品初心。

---

## 1. 产品定义

### 1.1 一句话定义

> 一台面向 6–15 岁儿童家庭的常驻 AI 运动伙伴，通过明确任务、视觉动作识别、可信反馈和适度陪伴，帮助孩子更容易开始、独立完成并愿意再次运动，同时让家长少催促、少监督，并能理解真实运动结果。

### 1.2 我们真正提供的不是哪些东西

本产品提供的不是“更多儿童内容”，而是一次次真实运动更容易发生。它不是：

- 儿童聊天机器人；
- 游戏大厅或体感小游戏合集；
- 依靠广告、弹窗和商城维持活跃的平台；
- 面向家长的信息流社区；
- 只记录数据但不帮助儿童开始和完成的运动仪表盘；
- 未经体育规则约束、自由生成儿童运动处方的 AI 教练。

### 1.3 产品初心

1. **让运动发生**：孩子真的开始并完成，比打开 App、浏览内容或领取奖励更重要。
2. **把监督变成支持**：技术替代家长反复催促和人工计数，但不把家长变成远程监控者。
3. **让努力被可信地看见**：识别、计数、保存和恢复必须尊重孩子已经付出的运动。
4. **用陪伴降低阻力**：角色、声音和奖励帮助运动，不争夺运动的主角位置。
5. **保护长期信任**：不以儿童冲动消费、公开排名、广告注意力或虚假精确感换短期收入。

## 2. 定位

### 2.1 人群定位

| 角色 | 核心需求 | 产品承诺 | 不承诺 |
|---|---|---|---|
| 6–9 岁儿童 | 看得懂、容易开始、有即时回应 | 图形/语音优先、短流程、温和反馈 | 复杂设置、公开竞争、开放社交 |
| 10–12 岁儿童 | 挑战、进步、自主完成 | 个人目标、个人最好成绩、可理解成长 | 付费决定权、战力式排名 |
| 13–15 岁青少年 | 自主、专业感、隐私 | 自主目标、克制表达、隐私控制 | 幼龄化强迫陪伴、家长全程监控 |
| 家长 | 少催促、真实完成、边界可控 | 轻量任务、结果先看、异常透明、权限可控 | 广告轰炸、焦虑营销、伪科学评分 |
| 体育老师/学校 | 任务易执行、结果易回收 | 经授权的任务与必要结果闭环 | 远程开启家庭摄像头、获取无关家庭数据 |

6–15 岁跨度很大，因此“同一功能、同一视觉、同一语气适用所有年龄”只能作为待验证假设，不能默认成立。

### 2.2 痛点定位

产品优先解决四个连续问题：

1. **开始难**：运动意图到真正开始之间有寻找入口、摆放、理解任务和情绪阻力。
2. **坚持难**：重复动作枯燥，错误反馈或努力未被识别会快速破坏动机。
3. **完成不可信**：孩子、家长和老师缺少一致、可理解、不会轻易丢失的结果。
4. **家长监督成本高**：家长需要反复提醒、现场计数和确认是否完成。

产品暂不把“缺少社交内容”“缺少小游戏”“缺少可购买皮肤”定义为核心痛点。

### 2.3 场景定位

- 第一场景：家庭固定运动空间中的短时、重复运动。
- 第一触发：家庭任务、学校任务、自主运动或克制的设备邀请。
- 第一闭环：任务/选择 → 入镜 → 准备 → 运动 → 反馈/恢复 → 完成 → 结果。
- 设备端承担运动当下；家长端承担任务、权限、结果和复盘。
- 社区、内容或商业入口不得打断上述闭环。

### 2.4 价格与商业定位

当前价格尚未冻结，但商业化必须遵守：

- 购买硬件后，基础运动闭环不得被二次付费墙拆断。
- 不在儿童端展示第三方广告、促销弹窗、充值入口或倒计时诱导。
- 不出售影响识别、计数、公平性或基础成长反馈的“特权”。
- 增值优先面向家长明确购买的专业课程、家庭服务、经审核计划或可选内容。
- 装扮/IP 若进入，必须与真实运动行为或家长购买相关，不建立儿童自行充值循环。
- 评价商业设计时同时看收入、打扰率、核心任务完成率、家长信任和长期复用，不以付费转化单指标决定。

## 3. 产品价值排序

发生冲突时按以下顺序取舍：

1. 儿童身体与心理安全、隐私和家长信任。
2. 运动任务能否真实开始、完成和恢复。
3. 识别与结果是否可信、可理解。
4. 孩子是否愿意再次运动。
5. 家长是否减少催促和监督。
6. 专业内容、个性化和家校扩展。
7. 内容活跃、社区互动和商业收入。

低优先级指标不得通过伤害高优先级价值获得增长。例如，社区停留时长不能以减少运动完成为代价，付费转化不能以儿童冲动消费为代价。

## 4. 借鉴竞品时的辩证结论

### 4.1 Keep：完整能力不能抵消入口污染

`[个人体验]` 各类弹窗和广告过多，降低进入核心任务的效率与信任。

- **可借鉴**：成熟运动内容、计划和训练数据的组织方式，后续专项研究 AI 教练闭环。
- **不借鉴**：启动弹窗、交叉销售、促销占据首页、在训练路径中频繁索取注意力。
- **对本项目的规则**：儿童端启动后应直接进入今日任务/快速运动；非安全类弹窗默认不得覆盖运动入口。

### 4.2 betterWE 星球：借鉴低门槛表达，不照搬成人社区

`[个人体验]` 首页帖子和快速发布能降低表达门槛，让用户更有参与和持续使用动力。

- **可借鉴的机制**：真实经验被看见、低成本记录、同类家庭获得支持、使用后有表达出口。
- **不可直接照搬的形态**：让儿童公开发帖、浏览陌生人信息流、追逐点赞或暴露运动/身体信息。
- **儿童化转译**：
  - 家长端提供“快速记录”，记录孩子完成后的反馈、困难或亲子运动心得；
  - 默认家庭私密，可由家长选择分享给经治理的家长社区或学校小范围；
  - 儿童端用运动日记、心情选择、给伙伴一句话等私密表达替代公开帖子；
  - 首页优先显示今日运动、上次进步和家庭支持，不以帖子流作为默认首页主体。
- **待验证问题**：真正促使复用的是表达、被回应、获得建议，还是社区新鲜内容；不同机制必须分别测试。

### 4.3 BodyPark：借鉴清晰首页与闭环，拆开服务和硬件

BodyPark 必须分为两项研究：

1. **BodyPark 在线真人私教服务**：研究预约、真人回应、AI 与教练分工、付费服务闭环。
2. **BodyPark ATOM 硬件**：研究固定设备、运动中反馈、屏幕与 App 分工、姿态提醒和硬件订阅。

`[个人体验]` 首页结构值得借鉴。后续需要具体记录首页首屏内容、主要入口、信息层级和从首页到开练的步骤，避免只留下“好看/清楚”的笼统判断。

### 4.4 天天跳绳：认可运动游戏化价值，拒绝平台游戏化

`[个人体验]` 游戏、排行榜、会员和皮肤等杂项过多，体验接近小游戏平台，引发明显反感与失望。

- **辩证价值**：摄像头体感、即时计数、趣味反馈和家校任务能够降低一部分儿童运动门槛；这说明儿童需要及时反馈和适量趣味。
- **结构性风险**：游戏大厅、公开排行、虚拟币、会员和皮肤形成独立于运动的注意力与消费循环，首页和用户心智可能从“运动”迁移到“玩与买”。
- **对本项目的规则**：只做轻量游戏化，不做游戏平台化。奖励来源必须是有效运动，不能靠登录、点击、观看广告或充值获得运动优势。

### 4.5 满分运动：专业视觉可学，商业压力必须隔离

`[个人体验]` UI 风格获得正面评价，但商业化较重，明显影响整体体验。

- **可借鉴**：清晰、专业、与儿童运动相符的视觉层级；课程/动作/结果的表达方式应进一步拆解。
- **需警惕**：课程售卖、会员入口或促销若侵入核心任务，会让专业信任转化成销售压力。
- **对本项目的规则**：视觉可以专业且有活力，商业入口必须与运动流程隔离；儿童端不承担成交任务。

## 5. 社区与内容边界

### 5.1 为什么不简单地说“做社区”或“不做社区”

betterWE 星球显示表达和同伴经验可能促进参与；天天跳绳也说明社交、排名和虚拟物品可能迅速反客为主。因此要保留“被支持”的价值，拒绝“争夺儿童注意力”的结构。

### 5.2 允许、需验证、禁止

| 级别 | 能力 | 约束 |
|---|---|---|
| 允许 | 家庭私密运动日记、儿童心情反馈、家长快速记录、完成后鼓励 | 必须由真实运动或家长主动触发，不公开儿童敏感信息 |
| 允许 | 个人最好成绩、与自己比较、家庭共同目标 | 可关闭、避免羞辱和焦虑 |
| 需验证 | 经治理的家长经验内容、学校小范围成果分享、异步共同挑战 | 家长明确选择；最小数据；内容审核；不默认公开 |
| 需验证 | 主题装扮、角色内容 | 不影响运动公平，不建立儿童充值循环 |
| 禁止 | 第三方广告、启动促销弹窗、儿童直接充值、抽卡、战力 | 与产品初心冲突 |
| 禁止 | 陌生人私信、儿童公开发帖、公开身体数据、全站排名 | 儿童安全、隐私与心理风险不可接受 |
| 禁止 | 以浏览、点赞、在线时长替代运动作为成长来源 | 会使产品从运动伙伴变成内容平台 |

### 5.3 首页原则

设备端首页只回答三件事：今天要不要运动、怎样最快开始、上次努力带来了什么。建议优先级：

1. 今日任务/快速开始。
2. 设备状态和是否可运动。
3. 上次结果、个人进步或伙伴反馈。
4. 家庭支持或克制的经验内容。
5. 设置及次要入口。

不得优先出现广告、商城、帖子瀑布流、活动 Banner、公开排行榜或多个促销弹窗。

家长端可以承载更多内容，但默认首页仍应“结果与行动优先”：今日状态、待处理任务、最近结果、异常/授权，其次才是经验内容和服务入口。

## 6. 功能准入测试

任何新功能进入路线图前必须回答：

1. 它改善运动主线的哪个节点？
2. 服务儿童、家长还是老师？谁是真正受益者？
3. 它依赖真实运动，还是可以脱离运动独立形成使用循环？
4. 它会不会增加从首页到开始运动的时间、选择或弹窗？
5. 它是否制造比较、消费、身体焦虑、隐私或陌生人风险？
6. 儿童不用它，是否仍能完成基础运动闭环？
7. 收入来自家长的明确选择，还是儿童的冲动与注意力？
8. 用什么指标证明它让运动更好，而不是仅让停留更久？

以下任一情况默认否决，除非经过儿童安全、用户和产品负责人共同评审：

- 核心价值主要来自非运动停留时长；
- 需要第三方广告或儿童端付费转化才能成立；
- 默认公开儿童身份、声音、图像、身体或运动数据；
- 通过输赢、稀缺、连续签到或损失厌恶逼迫儿童使用；
- 使核心运动能力因未付费而不可完成或明显不公平；
- 无法解释其对开始率、完成率、再次运动或家长负担的改善。

## 7. 关键指标与反指标

| 目标 | 正向指标 | 反指标/护栏 |
|---|---|---|
| 更容易开始 | 提醒/自主意图到开练的时间与开始率 | 首页停留、弹窗关闭次数、成人介入率 |
| 更容易完成 | 开始到完成率、中断恢复率 | 误计/漏计、努力丢失、挫败退出 |
| 愿意再次运动 | 7/30 日再次运动、主动运动比例 | 仅浏览内容、仅签到或仅装扮的活跃 |
| 家长更省心 | 催促次数下降、结果查看与理解 | 家长设置负担、告警焦虑、通知打扰 |
| 商业可持续 | 家长主动购买、退款率、服务续费 | 儿童误购、广告打扰、付费后核心体验差异过大 |
| 社区/内容有价值 | 内容后开始运动、获得有效支持 | 信息流时长、陌生互动、身体比较、举报与隐私事件 |

产品评审不得把 DAU、停留时长、帖子数、点赞数或充值额单独当作成功指标。

## 8. 当前已确认与待验证

### 已确认的产品原则

- 运动训练是绝对主线。
- 陪伴服务于开始、坚持和完成，不发展成开放聊天主线。
- 基础运动闭环不依赖广告、皮肤、公开排行榜或儿童充值。
- 儿童端不承担成交任务。
- 可以借鉴社区的表达与支持机制，但不能直接照搬成人帖子流。
- BodyPark 服务与 ATOM 硬件分开研究。
- 健萌竞品正式名称采用 `betterWE 星球`。

### 待用户与实测验证

- 三个年龄段是否需要不同首页、角色语气和挑战机制。
- 家长快速记录/经验内容是否真正提升再次运动，而不是只提升内容消费。
- 独立硬件是否显著降低摆放与开始摩擦。
- 家长最愿意为可信完成、专业纠错、陪伴还是家校闭环中的哪一项付费。
- 课程、计划、角色内容中哪些适合增值，且不会破坏基础体验。
