# 竞品软件体验观察记录 V1.0

> 记录日期：2026-09-18  
> 证据性质：用户个人体验，`n=1`；用于形成待验证假设，不外推为全体用户结论  
> 后续补证：需要对应版本、平台、体验日期、页面截图或录屏、从首页到开始运动的步骤与耗时

## Keep

- `[个人体验]` 各类弹窗和广告过多。
- 初步影响：核心入口被商业内容争夺注意力，增加开始运动前的认知和操作成本。
- 可借鉴：成熟运动内容、训练计划和 AI 教练闭环，需另行按任务流体验。
- 不借鉴：启动弹窗、促销覆盖、训练路径中的交叉销售。
- 待补：弹窗类型、出现频次、是否能永久关闭、关闭后到开始训练的步骤。

## betterWE 星球

- `[个人体验]` 首页帖子和快速发布体验较好，能增强参与和持续使用动力。
- 初步机制：降低表达成本，让使用后的感受或经验被记录、被看见和被回应。
- 儿童产品风险：公开发帖、陌生人信息流、点赞竞争以及身体/运动信息暴露。
- 转译方向：家长快速记录、家庭私密运动日记、儿童私密心情反馈、经治理的家长经验内容。
- 待验证：驱动复用的是表达、回应、专业建议还是内容新鲜感。

## BodyPark

- `[个人体验]` 首页结构具有借鉴价值。
- 研究拆分：在线真人私教服务与 ATOM 硬件分别研究。
- 待补：首页首屏有哪些模块、第一视觉焦点、主要按钮、从首页到开练的路径、商业入口的位置。

## 天天跳绳

- `[个人体验]` 对产品感到反感和失望；游戏、排行榜、会员和皮肤等杂项过多，接近小游戏平台体验。
- 辩证价值：体感游戏、即时计数和趣味反馈可能降低部分儿童开始运动的阻力；家校任务也有实际流程价值。
- 结构性风险：游戏、排名和付费装扮形成独立注意力/消费循环，使运动从目的变成获得游戏权益的手段。
- 对本项目启示：保留轻量游戏化，拒绝游戏平台化；奖励只由真实运动产生，不做广告、儿童充值和付费运动优势。
- 待补：最反感的三个具体页面/节点，以及仍认为真正有效的一个运动功能。

## 满分运动

- `[个人体验]` UI 获得正面评价。
- `[个人体验]` 商业化过重，虽然可能贡献公司收入，但明显降低用户体验。
- 可借鉴：专业、清晰、有运动感的视觉与信息层级。
- 不借鉴：商业入口侵入核心任务、课程/会员销售压力覆盖训练价值。
- 待补：喜欢的具体页面、颜色/布局/信息层级；商业化最影响体验的节点。

## 跨产品初步主题

1. **首页应提高开始运动的效率，而不是最大化可运营位置。**
2. **参与感值得保留，但儿童产品应优先采用私密表达、家长控制和真实运动触发。**
3. **游戏化可以服务动作反馈和坚持，但不能形成脱离运动的游戏平台与消费循环。**
4. **专业 UI 能建立信任，过重商业化会反向消耗这种信任。**
5. **收入必须与儿童体验设置隔离带：儿童端不承担成交任务，基础运动闭环不可拆卖。**
