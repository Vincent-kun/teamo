# 儿童 AI 运动陪伴机器人微信小程序 MVP

这是根据《儿童AI运动陪伴机器人_完整产品UE_Demo_V7.3》整理的家长端微信小程序 MVP 工程，可直接导入微信开发者工具。

## 视觉方向

当前版本已结合 Teamo MVP 形象统一视觉语言：暖白背景、深色圆屏、荧光绿色主操作色、橙色隐私滑盖和胶囊形设备轮廓。页面信息仍优先服务家长操作，不把概念展示内容直接搬入小程序。

当前视觉采用克制的亚克力玻璃语言：低饱和环境光作为背景，内容卡使用半透明白、细白描边、边缘高光与柔和模糊；粉、紫、青、桃色只作为透过玻璃的功能光晕。Teamo 荧光绿仅用于主要行动按钮，深青色用于设备状态和运动分析等重点信息，避免全页面透明或高饱和堆色。

- 品牌主张：一起动，更靠近。
- 核心路径：发出邀请 → 开始运动 → 实时反馈 → 查看成长。
- 隐私表达：突出物理遮挡与“无实时画面”的产品边界。
- 交互原则：一个页面只保留一个主要动作，重要按钮采用高辨识度绿色。

## 当前已实现

- 首页：设备状态、今日运动、快捷动作、任务、AI 入口和最近记录。
- 动作库：展示七类目标动作；开合跳、深蹲起为当前MVP可发送动作，其余明确标记算法评审或后续适配状态。
- 任务：支持单项运动或已生成的 AI 计划，设置周期、时间与目标设备，并显示设备回执、支持取消。
- AI：根据孩子目标生成 7 天运动计划，保存并发送到设备；支持常见问题和文本提问演示。
- 成长：周运动数据、亮点、最近分析、全部记录入口与日常姿态提醒。
- 我的：家长信息、可编辑孩子资料、设备、消息、隐私和使用帮助。
- 设备：模拟在线状态、当前任务、真实状态中文映射、开始/暂停/继续/结束、能力开关与最近设备动态。
- 运动记录与分析：按次查看完成状态、来源设备、完成率、有效动作、节奏和姿态问题。
- 姿态提醒：说明坐姿、低头、距离提醒的使用范围与非医疗边界。

## MVP 边界

- 当前聚焦家长端与设备端运动闭环，不加入学校端任务。
- AI 运动计划与问答目前使用模拟数据，接入真实服务后再提供个性化结果。
- 暂不加入饮食拍照分析、医疗判断、多人家庭权限和正式支付能力。

## 会议纪要对齐

当前页面已经按 2026 年 9 月 24 日产品讨论结果收紧为三条 MVP 主线：家长创建运动邀请、设备执行运动、学伴积分养成。详细提炼和本次调整见 `会议纪要_UI提炼与优化说明.md`。

## 当前连接方式

工程默认使用模拟数据，不依赖真实服务端。真实接口统一放在 `miniprogram/services/api.js` 中：

- 小程序与服务端：HTTPS + WebSocket。
- 服务端与设备：建议 MQTT，也可替换为 WebSocket。
- 设备状态：`offline / idle / ready / running / paused / completed / error`。

## 运行方法

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹。
4. AppID 暂时使用测试号；获得正式 AppID 后替换 `project.config.json` 中的 `appid`。
5. 真实接口确定后，将 `miniprogram/services/api.js` 的 `USE_MOCK` 改为 `false`，并填写服务端域名。
