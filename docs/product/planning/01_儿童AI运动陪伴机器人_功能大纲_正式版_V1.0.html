01产品定位、用户与场景

统一定位：一款面向6～15岁儿童青少年的家庭AI运动陪伴机器人，通过视觉运动识别、自动计数与反馈、家庭与学校任务、陪伴式交互和成长记录，让孩子更愿意主动运动，让家长更省心，并持续形成可理解的运动成长数据。长期定位：家庭常驻AI运动成长伙伴。购买决策者为家长，商业方向以To C为主。运动是核心功能，陪伴是情感引擎，家校是差异化能力，智能训练计划是长期能力。竞品功能只用于理解行业能力、补充疑问和识别差异化，不等于本产品承诺。

儿童

负责运动、接受提醒、查看即时结果、与机器人互动。体验重点是少文字、快反馈、可独立完成。

家长

负责创建任务、查看运动结果和成长、管理设备与隐私、查看学校任务。

老师 / 学校

负责发布体育任务、查看完成结果和班级相关数据，前提是合作与授权成立。

功能归类原则

按“用户为什么需要它”归类，不按研发团队归类；重复功能合并，未理解功能保留缺口标记。

05A优先级讨论起点

模块建议先讨论的范围为什么与其他模块的关系
A 智能运动训练P0 核心 入镜、站位、七个动作、阶段判断、有效计数、反馈、暂停、完成和结果。这是“孩子能独立完成一次运动”的主链路。依赖摄像头、屏幕、扬声器和一次运动记录。
B 任务与训练计划P0 基础 家庭任务、今日任务、提醒、自主运动和任务状态；智能训练计划先放 P1。先让家长会布置、孩子看得懂并能开始。与家长端、学校任务和运动记录相连。
C 陪伴与激励P0 基础反馈 眼睛、短语音、开始/完成反馈和运动星；主动行为、成长、轻玩法再讨论。宠物要帮助开始和坚持，但不能盖过运动识别。由运动事件驱动，不单独做聊天玩具。
D 体态陪伴边界待评审 先保留提醒方向和验证入口，不作为运动闭环前置条件。价值明确，但需要单独验证误报、隐私和儿童接受度。与运动计数分开，不形成医疗结论。
E 家长端P0 基础 今日、任务、结果、设备和隐私；复杂趋势与高级成长后置。家长只需要布置和查看，不增加管理负担。接收任务、一次运动记录、设备状态和安全设置。
F 家校协同P1 试点 学校任务、家庭执行、结果回传；榜单、PK和长期档案后置。先验证家庭独立价值，再接入合作场景。依赖学校授权、数据边界和教师端。
G 设备与硬件P0 底座 摄像头、屏幕、扬声器、麦克风、网络、本地保存和供电。没有稳定设备，软件和算法体验无法成立。为识别、反馈、联网和安全提供基础能力。
H 账号/数据/同步P0 底座 账号绑定、任务、一次运动记录、离线暂存、恢复补传和去重。保证结果可信、可追溯，不因断网丢失或重复奖励。连接设备、App、Web 和学校结果。
I 隐私与儿童安全P0 底线 摄像头状态透明、权限、数据删除、原始视频最小化和提醒安全。儿童设备必须先让家长放心。贯穿摄像头、账号、任务、学校和排行榜。
会议建议：逐行确认“保留 / 调整 / 暂缓”，并记录结论、需要的证据、影响的功能行和负责人。没有会议结论的项目继续标记为“待讨论”。

06A验证闸门与证据

闸门要验证什么需要留下的证据未通过时怎么办
Gate 1 摄像头与人体姿态全身是否能被看到，站位提示是否让孩子看得懂。不同身高、距离、光线、衣着和遮挡下的测试记录。先调整机位、引导或动作范围，不继续堆叠玩法。
Gate 2 动作与计数七个动作能否判断阶段并稳定累计有效次数。人工计数对照、漏计/误计记录、可复现视频和识别日志。收窄动作范围或调整规则，不用静态页面代替真实能力。
Gate 3 屏幕与声音孩子能否看清大数字，能否听到短提示，反馈是否打扰运动。不同距离、家庭环境和音量下的可读、可听与延迟记录。减少信息和语音频次，优先保证计数和状态清楚。
Gate 4 完整运动闭环任务/自主开始 → 入镜 → 识别 → 计数 → 完成 → App 查看结果是否贯通。端到端演示、设备/App/Web 结果对照、异常恢复和家长/儿童观察。复盘核心价值是否成立，再决定后续扩展。
指标口径：开始率、Ready 成功、漏计/误计、运动完成、主动结束、结果一致、断网补传、家长理解度和儿童再次使用意愿，均需在真实测试后再确定目标数字。

07一页结论

产品核心

围绕家庭自主运动和家庭任务，形成“运动识别—反馈—完成—记录”的功能主轴。

陪伴差异化

宠物、宠物眼睛表情、语音、运动星和轻量激励服务于运动坚持，不把产品扩展成普通聊天机器人。

边界管理

七种动作是当前动作识别池；体态、家校、智能训练计划、排行榜、PK均保留讨论边界和授权条件。

后续使用顺序：功能大纲确认 → 优先级讨论 → PRD细化 → UE/UI → 研发评审。这里表达工作依赖关系，不表达日历时间承诺。
