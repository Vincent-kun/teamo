# PRD V3.0 → 11/15演示功能对应矩阵 V0.1

日期：2026-10-10。状态：需求对应与范围讨论稿，非已冻结演示清单。

权威输入：[现行PRD V3.0](../requirements/03_儿童AI运动陪伴机器人_PRD_V3.0.html)，状态REVIEW。本文覆盖PRD §01–22的功能、对象、异常、验收及待决事项，对应[演示范围](MVP软件演示范围与逐步细化_V0.1_20261010.md)的S01–S14与[决策台账](MVP关键问题与决策台账_V0.1_20261010.md)的D01–D15。R编号仅为本次追踪编号，不是PRD原生需求ID。

“核心建议”表示建议进入本次展示，尚待确认；“待裁剪”表示PRD已有要求但本次尚无纳入/延期决定；“后续评审”保留PRD自身的待评审/Target Product定位；“边界”持续生效，不因演示裁剪消失。当前无实机实现证据，映射不代表完成。七动作/学校/其他第一版功能若本轮不做，必须记录明确范围差异，不称已完成第一版。

## 5. 下一轮逐步细化与冻结方式

设备端详细行为及Flow已整理为[设备需求基线评审稿](../requirements/设备端需求基线_评审稿_V0.1_20261010.md)。用户本轮提出的动作示范明确形式新增S25候选、FR-SPORT-002和OPEN-001；PRD未冻结视频播放/缓存方案，不把新增表达当成PRD已批准要求。67×92mm记录为设计包络，厚度和轴定义待OPEN-007确认。跨目录入口见[需求基线导航](需求基线导航与评审入口_20261010.md)。

1. 以R01–R45为核对行，产品负责人逐项标记“本次纳入／本次延期／PRD自身后续待评审／持续边界”，绑定确认人和理由；状态不可留为笼统“后续”。
