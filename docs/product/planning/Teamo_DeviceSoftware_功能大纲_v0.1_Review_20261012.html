产品范围与运动闭环

面向 6–15 岁家庭，设备承载儿童运动入口、任务执行、视觉识别、实时反馈、结果记录与同步，以及基础运行管理。家长端负责布置任务、授权与查看结果；平台负责跨端任务和结果同步。陪伴服务运动。

家长布置任务 → 平台同步任务 → 设备接收任务 → 儿童开始运动 → 设备视觉识别 → 实时反馈指导 → 生成运动结果 → 同步平台

家长任务为本稿主链路；自主运动与学校任务是否纳入本次范围，需一并确认。原始摄像帧不持久化，日志与缓存仅保留必要结构化数据。
