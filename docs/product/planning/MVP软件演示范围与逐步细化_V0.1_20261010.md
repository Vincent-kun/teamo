# 2026-11-15 MVP软件演示范围与逐步细化 V0.1

日期：2026-10-10。状态：可供逐项确认的范围建议；未正式冻结、未宣称实现完成。

PRD逐项对应见[PRD到11/15演示功能矩阵](PRD到1115演示功能对应矩阵_V0.1_20261010.md)。该表补齐S15–S24：提醒延后、任务管理、运动星/PB、成长、今日、我的、体态、学校、撤回删除与规则计划。本文S01–S14是先行主链建议，不代表全部PRD范围；扩展池的延期尚未批准。PRD §07/16已明确离线可继续本地识别，D03待确认的是实现方案。

目标：在11/15以实体样机、真实家长端和后台展示一次可信运动，并证明暂停恢复、隐私关闭和断网补传。用户已要求尽快完全确定最终演示功能；本文把决定所需的范围、验收与依赖具体化。范围冻结需记录真实决定与责任，不能用候选设计或已有模拟页面代替。

## 1. 演示切片与平台

建议：一个家长、一个儿童、一台设备、开合跳一种真实动作；小程序为家长端，后台为真实任务与记录服务，设备为真实采集/识别/反馈/持久化。预配置网络与演示身份允许作为展示准备，但必须显式记录，不宣称已实现完整注册配网。

已有证据：9/29会议路线提出家长端/后台/设备交互/实体样机与11/15节点；硬件V2.0包含开合跳、深蹲起和基础姿态提醒。单动作、小程序优先和扩展延期是本轮建议裁剪，不改写完整产品承诺。

|必验异常|隐私关闭、倒计时离画、低置信度不造数、重复消息、断网补传、保存失败与断电恢复|影响数据/隐私正确性的行为不可用隐藏提示代替；舞台演示可选部分，完整记录必须提供|

## 3. 状态与页面细化

页面导航：Home → 任务/运动选择 → 站位 → 准备 → 倒计时 → 识别中 → 结束保存 → 结果。暂停和异常为分支；同步为并行状态。设备Home是待机/任务入口的语义，不预设大触控屏页面。

|状态|进入与守卫|允许操作/事件|退出与异常|设备表达/家长表达|
|---|---|---|---|---|
|待机/任务|启动恢复完成；有明确身份与任务状态|查看/接受任务；自主入口待决|任务接受进入隐私检查；忙碌新任务按策略拒绝|表情/任务图标+语音；任务状态卡|
|隐私阻断|硬件关闭或状态未知|本地解除/查看说明，不允许远程绕过|允许且明确后进入站位|隐私图标/灯+提示；最后确认状态与时间|
|站位|有有效任务、允许采集|调整位置、取消|稳定满足条件进入准备；暗光/故障阻断|一种主要原因+语音；无需实时家庭视频|
|准备|准备连续满足冻结时长|按已确认方式开始|确认后倒计时；条件失效退站位|准备符号+提示；已准备状态|
|倒计时|任务、入镜、隐私守卫均满足|取消；接收采集/隐私变化|结束再检查进入运动；离画退站位，隐私变化阻断|大数字+短音；即将开始|
|运动中|新的会话/已恢复；算法周期重置|有效事件、暂停、结束|达标/提前结束到待保存；离画/故障暂停|次数/目标+节制声音；权威进度|
|暂停|主动、离画、低置信度策略、隐私或采集异常|重新站位、恢复确认、提前结束|守卫满足后恢复；持续异常不计数|保留次数+原因；暂停原因|
|结果待保存|结束原因已记录，停止计数|执行原子保存及入队|成功到结果；失败到保存失败|结束反馈与保存状态；不可提前宣称记录已保存|
|保存失败|写入失败且数据仍保留|重试；恢复步骤由D10冻结|成功到结果；不可静默丢数据|错误提示/重试；记录尚未保存|
|结果|保存成功；完成或提前结束|查看、返回；后台同步独立进行|返回待机；同步失败仍保留结果|次数/结束状态；完整结果及同步状态|

每个状态继续细化为：线框、显示元素/语音、输入映射、数据源、进入/退出条件、异常/恢复、协议事件、验收脚本、Owner与实现证据。先做S02–S12主链，不等待全量108节点设计完成。

## 4. 接口与数据首包

以下为契约候选，10/12前需开发共同确认字段类型、必填、版本、错误码、读写权限、留存及删除规则：

- Task：taskId、taskVersion、childId、deviceId、action、target、unit、issuedAt、expiresAt。执行中不静默改目标。
- Command：commandId、protocolVersion、taskId、type、payload；重试复用commandId。回执区分收到/接受/拒绝/执行完成。
- AlgorithmEvent：sessionId、sequence、actionVersion、type、confidence/readiness、occurredAt；有效动作事件唯一。阈值和周期所有权共同确认。
- Session：sessionId、taskId、taskVersion、confirmedCount、activeDuration、state、pauseReason、startedAt、endedAt、endReason、algorithmVersion。设备为执行事实真源。
- Result：recordId、sessionId、真实目标/实际/用时/结束状态、savedAt、syncState；服务端按recordId幂等，确认前设备保留队列。
- Snapshot：deviceId、bootId、sequence、会话/任务状态、隐私已确认状态、错误、observedAt；App不使用本地动画或定时器冒充设备事实。

时间戳不能单独保证事件顺序；明确序号、重启和过期事件处理。原始视频帧只在内存处理；具体隐私、恢复与删除策略按D08/D10/D13落实。

## 6. 最终演示脚本候选

1. 展示版本、实体设备、家长/儿童/设备归属、允许环境和预配置步骤。
2. 家长创建开合跳20次任务；展示等待确认到设备已接受，设备开始引导。
3. 先不完整入镜，证明不能开始；调整站位，确认并倒计时。
4. 做12个有效动作；展示真实次数。暂停或离画，次数保持12。
5. 回位并按冻结方式确认；下一个有效动作计为13，继续到20。
6. 在完成前断开外网；仅在D03本地识别验证通过后继续运动。显示本地保存、待同步，家长端不假装收到结果。
7. 恢复网络；后台与家长仅出现一条记录，逐项核对次数/目标/用时/状态。
8. 切换物理隐私状态，证明关闭不能采集/开练；App展示已确认状态或离线时效。

提前结束、倒计时离画、重复指令、保存失败、运动中及写结果时断电另附回归记录，可按现场时长选择展示；不减少必验范围。展示时长待实际彩排记录，不预设已可在固定分钟内完成。
