## 2. 产品范围与责任

设备负责运动当下：任务或自主开始 → 明确目标 → 隐私检查与入镜 → 倒计时 → 识别与反馈 → 暂停/恢复或结束 → 结果保存 → 同步。家长端负责任务发布、授权和结果查看；平台负责业务传递与统一结果。绑定、删除和学校任务需要跨端责任确认。

一级功能按能力领域组织，不等同于菜单、页面或技术架构。功能模块代码保留v0.1以追溯，P0/P1前缀不决定模块内每个功能的优先级。动作是运动能力实例。

| 优先级 | 口径 |

|---|---|

| P0 | 核心闭环或儿童安全必需，拟纳入MVP |

| P1 | Phase 2候选，不能混入当前MVP承诺 |

| P2 | 规模化增强候选；本版暂不分配 |
