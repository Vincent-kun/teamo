## 沿用什么

手机端任务操作：任务页 → 创建运动邀请 → 单项运动/AI计划 → 动作与次数 → 仅今天/每天/隔天 → 提醒时间 → 核对设备 → 确认邀请。保留任务分类、接收回执与取消确认。当前是单孩子上下文，不新增默认的多人选择流程。

小程序当前可发送开合跳、深蹲起；其余动作保留后续状态。完整PRD七种动作与小程序MVP两种动作分别记录，不能把初步交互确认当作算法已验收，也不能静默缩减完整PRD。

手机端设备页是家长查看与控制设备的页面，不是孩子面对机身时的屏幕。孩子选择、站位、倒计时、计数、暂停恢复和保存，继续对照UE细化到软硬件可执行要求。
