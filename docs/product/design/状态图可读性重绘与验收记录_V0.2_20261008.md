# 状态与架构图重绘记录 V0.2

日期：2026-10-08。状态：设计候选；静态排版验证通过，读者理解与浏览器交互待验证。

## 问题与方法选择

旧版的固定三列网格没有表达主链顺序，异常回边穿插，所有节点相同视觉权重；职责关系与状态转移也混在同一种图里。本轮先选择语义，再选布局，保持完整模型并分层阅读。

- 能力树：包含关系，回答有哪些能力；不能用它表达执行顺序。[Mermaid Mindmap](https://mermaid.js.org/syntax/mindmap.html)
- 概念职责架构：明确职责、边界、单向关系、范围和图例；技术部署未冻结就标待评审。本图借鉴C4表达规则，不宣称已完成严格C4部署模型。[C4 notation](https://c4model.com/diagrams/notation)
- 责任泳道：每列一个责任主体，纵向按步骤读交接。本图是简化责任泳道，不是严格BPMN符号模型。[OMG BPMN](https://www.omg.org/spec/BPMN/2.0.2)
- 局部状态图：正常主链先展示，完整候选转移另展开；运动、网络、授权、上传独立建模，避免组合爆炸。[W3C SCXML](https://www.w3.org/TR/scxml/)

详细研究见同目录《专业状态与架构图作图方法研究_20261008.md》。上述方法分别解决不同问题，不能用一种漂亮布局取代状态语义。

## 实际实现

入口：`prototype/state-design-lab-prototype.html`，双击打开；页面不需要安装依赖或连接网络。数据源：`prototype/state-atlas-model.json`，保留12个功能域与108个候选节点。

使用本机已有 @viz-js/viz 3.25.0 / Graphviz 14.1.3，在生成阶段预渲染25张SVG（11个局部域各两种视图，加能力树、架构和泳道）。Graphviz dot以层次组织有向图并尝试减少交叉；不是自创九宫格布局。[Graphviz dot](https://graphviz.org/docs/layouts/dot/)、[Viz.js API](https://viz-js.com/api/)

图形与页面均有标题、范围、语义说明和图例。中文标签按估计字宽设置最小表格宽度，并用实际微软雅黑字体测量复核；修复了第一遍渲染中的文字越出节点。回边不参加前向分层，前向异常分支仍参与排名，不再把暂停/失败状态无关地浮在图顶。

默认入口是一次运动的跨端泳道。可以进入能力树、职责架构、局部状态图；局部图默认正常主链，按需展开全部候选转移。文字保持自然尺寸，图大时滚动/缩放；不把长图压缩到不可读。节点点击和键盘选择显示进出条件，保持图形滚动位置。导出SVG包含标题、范围和图例，不依赖工作台页面解释。

情境页保留8条预设场景，用来讨论双端表达：正常、离画、断网、隐私、存储失败、重启、删除、分析降级。这些是预设情境，不是业务状态机、真实识别或网络实现。PM范围表默认待决定，不删除完整能力框架。

## 本轮可检查的证据

- 25张图的Graphviz节点矩形边界检查：重叠0。
- 25张SVG使用微软雅黑测量节点文字边界：越界0。
- SVG三次曲线路径采样，排除源和目标节点后检查其他节点：穿节点0。属于采样检测，不能证明曲线每一点都不相交。
- 四个区域及四种图模式在Node隔离环境生成HTML成功，脚本语法通过。已复核多次生成时不重复注入图谱或提前调用render。
- 对泳道、能力树、架构、运动全转移图进行本地图像渲染与人工视觉检查；样例PNG供评审。

记录：`prototype/state-atlas-assets/layout-metrics.json`、`static-review.json`；源DOT与SVG一起保留。没有声称所有边交叉为0，也没有把0重叠等同0理解成本。

应用浏览器安全策略拦截file协议，未通过其他方式绕过；本轮未做实际浏览器点击、缩放、下载、键盘或窄屏布局验收。图像渲染检查不等于浏览器页面验收。

## 下一步与技能沉淀条件

读者复核四件事：能否找到开始与结束；能否指出哪个端拥有计数；能否追踪离画恢复；能否区分运动完成与同步完成。记录困惑节点和路线，再调整图。

当前保留研究和生成/校验脚本，不提前安装通用作图技能。用户确认可读性后，以 skill-creator / writing-for-agents 收束成短技能：问题到图类型路由、状态语义、成熟引擎、中文尺寸、渐进披露、导出与验证。项目启发阈值不得写成通用标准；不能把这次固定颜色和产品范围固化为所有项目要求。
