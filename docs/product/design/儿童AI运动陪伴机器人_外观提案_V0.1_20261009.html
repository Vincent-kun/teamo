1. 评审会上必须先拍板的三件事

#决策点选项与影响状态
1屏形：圆屏 vs 方屏 圆屏（渲染图方向，学伴表情载体，360×360 QSPI）外观最优但驱动/触控/宽度代价大；方屏 1.69″（240×280 SPI）省空间、MVP 更快，但外观需要重画。 未闭环
2机身包络：60×90 是否放弃 9/24 拍板"约 60×90mm 掌心小主体"；10/8 核算圆屏方案外宽下限 60.50mm、圆屏+相机同前脸需外高 ≥88.50mm，90mm 高仅剩 1.5mm 余量，装不下大圆角、底部的声孔与滑盖机构。 冲突待拍板
34G 是否进首版 内置 LTE 需要独立天线净空区（10/9 试验：42+20+10+4=76mm 宽），直接把机身从"方屏 Wi-Fi 的 63mm 宽"推到"76mm 宽"；Wi-Fi 优先则可保紧凑。 未闭环

2. ID 渲染方向（当前唯一已定的外观基准）

以下三图为产品外观的现行视觉基准（来源：prototype/teamo-ui-flow-html 资产）。UI 边界文档明确：仅参考其机身、圆屏与学伴眼睛作为初始基准，最终方向待本轮评审确认。

设计语言解读（从渲染图提取）

  • 整体形态：竖向扁胶囊，局部平前脸、顶部小圆角、平底、前后分壳、独立内支架——与 10/8 尺寸文档的形态建议一致；不采用整面半圆端部吞掉屏角的纯体育场轮廓。
  • 屏幕即面孔：黑色圆屏不是"显示屏"，而是学伴的脸——黑底上两只白色眼睛即待机表情。这是产品角色化的外观核心，圆屏方案的外现价值最高。
  • 隐私滑盖 = 橙色标志件：镜头 + 橙色物理滑盖横置于顶部槽内。橙色既是儿童产品的高可见点缀色，也是"摄像头开关"的状态符号——滑盖关即物理断视觉，对应儿童隐私底线（视频不持久化）的可见化表达。
  • 实体按键：屏下实体圆键（主键）+ 右侧长条键；渲染图未体现触控，与"触控是否首版必需"的未闭环决策一致。
  • 背面：上置圆形扬声器孔阵，底部 USB-C；侧面极薄轮廓对内部堆叠（电池 7.2mm + 载板 10mm + 屏预算）提出硬约束。

4. CMF 初始方向（提案值，非最终）

要素方向理由
主体色柔白（哑光）渲染图基准；儿童房场景亲和、耐脏折中
点缀色橙色（仅滑盖一处）单强调色原则；滑盖是唯一需要"被一眼看到"的交互件（隐私状态）
屏幕区黑色镜面圆窗表情面孔载体；息屏时整体如"脸"
按键与壳同色浅灰低调，不与滑盖争夺视觉
材质/工艺塑料前后分壳；本阶段 3D 打印试片壁厚 2mm/侧为初值，先打槽/螺柱/卡扣试片用卡尺校误差，再谈表面工艺

设备端 UI 配色另按《设备端UE参考与视觉边界》：深中性底 + 单一强调色；禁止复制参考页的渐变、庆祝粒子与复杂卡片。

5. 尺寸现状：三套讨论方案 vs 拍板包络

核心矛盾（不得静默处理）：外观理想是 9/24 拍板的"约 60×90mm 掌心小主体"；硬件核算的现实是——圆屏＋内置4G 的可行机身落在 73–76mm 宽、118–124mm 高（S2/S3），即便方屏 Wi-Fi 优先也要 63×102mm（S1）。"掌心"与"圆屏+4G"目前不可兼得，评审会须明确牺牲哪一头。

7. 待评审问题清单（外观相关摘录）

  • 圆屏是不是必须？方屏是否允许作为 MVP 外观？（决定 ID 是否推倒重画）
  • 触控是否首版必需？渲染图为纯实体键方案。
  • 60×90 拍板包络：维持（则屏/4G 必须让步）还是放宽（则"掌心"口径作废，需同步修订产品定义文档）？
  • 4G 内置与否——影响机身宽度与天线净空，进而影响整体比例。
  • 滑盖机构：与相机 24mm 安装深度的叠加高度、滑动手感与寿命，"滑盖加高另核"。
  • 镜头 FOV：MIS5001(B) 未确认 120–130°，若换镜头则顶部开孔与滑盖行程重算。
  • 背面扬声器孔阵位置与后腔 35×30×10mm 净空的匹配。
  • 按键数量与功能分配（屏下圆键 + 右侧键 是否够用）。
