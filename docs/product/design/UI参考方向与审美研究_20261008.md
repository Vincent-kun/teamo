# UI 参考方向与审美研究

研究日期：2026-10-08。三套方案均比较家长首页、任务设置、设备实时计数、运动结果，保持相同文案、数据、任务和异常范围。MVP 由 PM 决定。本次仅研究，不产生费用或改动产品。

## 证据边界

产品官方资料用于借鉴功能与端侧职责；设计系统用于规则；Behance 原作者项目和 Awwwards 作品仅作审美候选。网页文字与作者/奖项元数据已核验，部分网页仅搜索索引可读取或正文受阻，未声称完整观看图片、视频或实际操作产品。

## 三个方向

### A 活力运动场

直接参考：Nex Playground。拟议配色 #F5F7EE / #17251E / #176844 / #F1BC38，是本项目提案，不是抄录品牌色。

排版：紧凑粗体标题＋等宽数字＋清晰无衬线正文。布局：运动场式分区；主任务横幅＋两列项目，计数页大数字与阶段进度。动效：计数即时更新，阶段完成短促一次强调；无持续背景运动。双端与年龄：儿童明确挑战与短反馈，家长清晰任务和记录；高年龄段压低角色占比。

- [Nex Playground — Jump for Joy](https://prod.nexplayground.com/playground)（product-primary）：借鉴 自然身体动作、低步骤开始、家庭运动场语境；不借鉴 电视多人游戏复杂度、商业图库、产品参数直接外推。
- [Playground agency corporate site — Honorable Mention 2018](https://www.awwwards.com/sites/playground-corporate-website)（award-aesthetic-only）：借鉴 有限色彩与强层级作为待视觉复核方向；不借鉴 不是 Nex；奖项不证明儿童可用性。

### B 温暖陪伴屋

直接参考：Yoto Player。拟议配色 #FBF4E8 / #34322D / #315B53 / #B75535，是本项目提案，不是抄录品牌色。

排版：圆润无衬线标题，正文保持标准字形，计数使用清晰等宽数字。布局：留白与单焦点，少量角色贴纸＋大操作卡；结果像简短成长记录。动效：角色只在准备/完成回应，运动中静止；减少动效时淡入或无动画。双端与年龄：6–8 图形与语音引导，9–12 可选角色，13–15 不强制萌系；家长素净记录。

- [Yoto Player 3rd Generation official product](https://us.yotoplay.com/yoto-player)（adjacent-product-primary）：借鉴 儿童自助低复杂度、内容先下载后离线、物理设备与家长管理分工；不借鉴 卡片硬件、无摄像头音频产品能力不可等同本项目。
- [Kids Yoga — Anastasiia Unhur, client Olga Gorokh, illustrator Katya Reyda, 2021](https://www.behance.net/gallery/111451045/UI-UX-Design-Kids-Yoga-App)（creator-portfolio-aesthetic-only）：借鉴 家庭运动与插画协作主题；图片尚待人工复核；不借鉴 不是上线功能证据，不复用未授权插画。

### C 清晰成长仪表

直接参考：Fitbit Ace LTE。拟议配色 #F4F6FA / #182A3A / #2F5DA8 / #D36A32，是本项目提案，不是抄录品牌色。

排版：语义字体层级＋等宽数字，主指标粗体，标签保守字号。布局：数据优先、分层卡片与列表，计数居中＋单进度，结果分完成与同步。动效：进度有目的短动画、完成庆祝一次；角色在结果出现。双端与年龄：儿童只显示当前目标与下一步，家长任务/设备/活动记录；13–15 易保持成熟。

- [Google Fitbit Ace LTE](https://store.google.com/product/fitbit_ace_lte?hl=en-US)（product-primary）：借鉴 活动进度、轻角色激励、父母应用职责区分；不借鉴 定位/电话/付款/游戏解锁不进本项目，7+ 定位不能证明适合全部 6–15。
- [Material 3 Applying type](https://m3.material.io/styles/typography/applying-type)（design-system-primary）：借鉴 display/title/body/label 职责，动态数字等宽避免位移；不借鉴 不机械复制默认尺寸到远距离设备。

## 相同四屏的具体差异

| 屏幕 | 活力运动场 | 温暖陪伴屋 | 清晰成长仪表 |
|---|---|---|---|
| 家长首页 | 今日任务横幅＋动作分区 | 今日陪伴卡＋简短记录 | 今日目标＋活动记录列表 |
| 任务设置 | 清晰项目选择＋目标调节 | 一页一组、短句步骤 | 表单明确标签＋总结预览 |
| 实时计数 | 数字＋阶段轨道 | 数字＋静态陪伴角色 | 数字＋单进度指标 |
| 结果 | 完成徽章＋结构化数据 | 温和反馈＋事实记录 | 完成量＋质量依据＋同步状态 |

以上均为设计建议；不将任一产品营销页当作完整 UI 截图或交互规范。

## 品牌设计系统依据

[Apple HIG Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility?changes=latest_maj_6_3&language=objc) 明确支持大字号，谨慎使用快速和闪烁动画，并响应 Reduce Motion。借鉴可调整、可读及动效替代，不直接复制平台材质到小设备。

[Material 3 Applying type](https://m3.material.io/styles/typography/applying-type) 使用 display、headline、title、label、body 五种角色；动态值可用等宽数字降低布局位移。家长端按语义命名字体 token；设备数字独立按实机阅读距离校准。

[Carbon v10 Expressive typography](https://v10.carbondesignsystem.com/guidelines/typography/expressive/) 区分产品与编辑营销的字体表达，支持正文样式保持一致。它是 v10 文档，引用其分工原则，不宣称当前组件版本。儿童设备可有表达性标题，家长表单与结果维持务实正文。

[Playground 机构原站](https://www.playground.it/) 由 Awwwards 条目链接到原作品；获奖的是机构官网，非 Nex Playground。仅用作审美候选，须再看截图确认有限色彩与层级。[Lusion 原站](https://lusion.co/) 可核验自述 3D、motion 与互动叙事，但本轮奖项页面请求超时，因此不把 Lusion 获奖详情作已验证依据，也不推荐重 WebGL 到 MVP。

Behance Kids Yoga 可核验原作者 Anastasiia Unhur、客户 Olga Gorokh、插画 Katya Reyda、2021；正文直接打开失败，搜索索引能提供项目描述。另 [Kids Fitness Website — Soumya Avinash Maheshwari, 2022](https://www.behance.net/gallery/159444199/Website-UI-Kids-Fitness-App) 元数据可读而直接请求 403，仅列候选，不提出未看图片的具体造型结论。

## 什么算好设计：三套共同验收

以下为本项目建议，需验证，不是来源中现成儿童标准。

- 首屏只有一个最突出的操作，能说清当前状态和下一步；退出/暂停稳定可找到。
- 实时计数数字不因位数变化横跳；在实际运动距离、实际屏幕亮度下读得清，不能用手机字号猜设备字号。
- 6–8 岁用图形＋短语＋可重复语音；9–12 保留自主选择；13–15 可选择弱角色/更成熟外观。年龄分层是假设，须三组用户验证。
- 运动中角色不挡计数，反馈不要求持续盯屏；完成庆祝一次且可减少动效。
- 家长端任务、设备、结果分清；完成与已同步分别标注；结果不把算法不确定性呈现成确定评价。
- 中文优先本机可靠无衬线字体回退；字体资源失败仍可阅读，不使用图片文字；授权与摄像头状态用图标＋文字。
- 离线时明确已保存、待同步和可执行动作；装饰素材可失败，计数和关键文案不能依赖网络下载。Yoto 的离线音频仅启发该原则，不证明本项目已能离线识别。
- 三套用同内容截图与点击脚本评审，分别记录发现开始入口、读出计数、解释结果与断网恢复的正确率；不能只投票最漂亮。

建议先做每套四屏共十二屏静态对照，再对最有潜力两套搭同一主链交互，第三轮结合孩子和家长测试收束。框架能力不随风格删减，MVP 范围交 PM 确认。
