## Product Definition

Teamo 是面向6–15岁儿童的家庭常驻AI运动陪伴机器人。设备以角色化陪伴帮助儿童开始、完成并持续运动，提供可信结果；陪伴始终服务于运动。

核心闭环：设备陪伴 → 运动准备（含识别就绪确认）→ AI识别 → 动作计数 → 实时反馈 → 运动结果 → 同步家长（离线先保存，联网后补传）。

| 责任主体 | 负责什么                                                  | 不负责什么                                        |
| ---- | ----------------------------------------------------- | -------------------------------------------- |
| 设备端  | 摄像头本地处理与动作识别、识别就绪与准备判断、计数、任务保存与执行、运动结果生成、本地反馈、设备状态与维护 | 家庭权限管理、支付、开放聊天、AI训练计划生成、公开社交、视频录像/上传/回放、医疗判断 |
| 家长端  | 授权与绑定、任务安排、设备设置、结果查看                                  | 替代设备实时计数；不默认远程开启摄像头                          |
| 云端   | 获授权任务、状态、结构化结果与资源协作                                   | 不绕过授权，不接收原始家庭视频                              |

摄像头仅用于人体检测与动作识别；原始视频不上传、不持久化。不引入成人负重、KG容量或组数作为儿童成长指标。

## MVP 首发闭环（速览）

设备启动自检（6.1.4）→ 确认绑定与儿童归属（1.1、4.3.6）→ 陪伴状态（3.6、3.3.3）→ 选择运动或家庭任务（2.1、2.4）→ 识别就绪确认（2.2.9）→ 准备与有效计数（2.2.1–2.2.4、3.3.1）→ 状态语音与角色反馈（3.3.2–3.3.3）→ 结果保护与同步（2.2.5–2.2.7、2.5.2、5.1–5.2）。

识别就绪与准备条件未满足不得开始有效计数；中断恢复保留可确认进度；异常日志贯穿全程并联网同步平台，不作为运动结果或奖励。
