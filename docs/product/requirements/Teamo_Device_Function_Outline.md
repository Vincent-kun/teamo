## Product Definition

Teamo 是面向6–15岁儿童的家庭常驻AI运动陪伴机器人。设备以角色化陪伴帮助儿童开始、完成并持续运动，提供可信结果；陪伴始终服务于运动。

核心闭环：设备陪伴 → 运动任务 → AI识别 → 实时反馈 → 运动结果 → 成长激励 → 家长同步。成长增强项尚未批准时，基础运动结果与必要鼓励仍应完整提供。

| 责任主体 | 负责什么 | 不负责什么 |
|---|---|---|
| 设备端 | 【修改】摄像头本地处理与姿态识别、动作判断、次数统计、任务保存与执行、运动结果和成长星奖励结果生成、本地反馈、设备状态采集与结果上报 | 用户家庭管理、云端数据管理、历史数据管理、AI训练计划或建议生成、支付、开放聊天、公开社交、视频监控或回放 |
| 家长端 | 【修改】通过小程序提供登录、儿童档案、设备绑定、任务安排、外部计划提供、设备设置及记录查看入口 | 替代设备本地运动识别或默认远程开启摄像头 |
| 云端平台 | 【修改】管理账号家庭、设备、任务及历史数据，同步保存设备上报的运动记录和成长星奖励结果 | 重新识别设备运动、代替设备产生成长星奖励结果、接收家庭原始视频或绕过家长授权 |

【修改】摄像头仅用于本地处理与识别；视频不上云，MVP不上传视频、不保存运动视频；提醒不保存视频或截图。识别所需即时采集不构成录像功能。设备端不承接会员成交，不引入成人负重、KG容量或组数作为儿童成长指标。附件规格仅为BodyPark参考，不构成Teamo硬件承诺。
