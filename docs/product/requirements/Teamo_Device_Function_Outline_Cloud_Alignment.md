# Teamo 儿童AI运动陪伴机器人
# MVP设备端软件功能大纲 v1.1

> **用途**：基于设备端v1.0导出稿，补齐云端业务要求对应的设备能力，供评审后展开UE IA与PRD。  
> **版本**：v1.1.0（业务简称v1.1）。  
> **更新日期**：2026-10-13。  
> **版本说明**：保留原4个一级功能、4个二级功能及全部9项子功能编号、名称、说明和优先级；仅在原功能树中新增。  
> **来源**：[设备端v1.0导出稿](../../../archive/imports/2026-10-13/Teamo_Device_Function_Outline_v1.0_export.md)、[云端平台v1.0](../../../archive/imports/2026-10-13/儿童AI运动陪伴机器人_云端平台功能大纲_V1.0(1).md)。  
> **文档关系**：本稿为导出稿的独立云端对齐修订；与仓库另一份[XMind源图功能大纲](Teamo_Device_Function_Outline.md)编号含义不同，不互相替代。现行PRD、功能规格和UE IA未随本稿改写。  
> **范围**：设备承担儿童交互、本地运动执行、识别反馈、缓存与同步；家长身份、档案创建、任务编排及奖励结算留在小程序/云端。一级功能分类不等同实际页面导航。

## 优先级说明

| 优先级 | 含义 |
|---|---|
| P0 | MVP必须支持的设备闭环能力；新增项为待评审建议，尚未冻结排期 |
| P1 | 重要增强能力 |
| P2 | 未来扩展能力 |

原9项P0保持不变。新增项参照云端优先级并按设备职责映射，不将云端“全部P0首发”自动视为设备已批准范围。面向6–15岁；原始视频及图片不上云、不落盘；本地临时帧只在内存处理，结束或停止采集后清理。

## 范围对齐与待确认项

| 项目 | 本稿处理 |
|---|---|
| 动作范围 | 保留现行已确认演示动作：开合跳、深蹲起、高抬腿；云端输入含跳绳，需联审后才能加入，不由本稿替换深蹲起 |
| 配网承载 | 接收家庭Wi-Fi配置并反馈进度；云端提出蓝牙近场、仅2.4GHz，硬件能力及承载方式待联审；MVP不补入蜂窝能力 |
| 升级供电 | 电池机型的20%升级阈值为云端建议，待硬件确认；无电池机型按供电稳定条件评审 |
| 摄像头控制 | 远程开启必须符合有效授权与本地关闭约束，提供采集指示；不开放远程视频，不允许远程指令绕过授权撤回 |
| 缓存上限 | 云端提出100条，运动记录与任务变更共用还是分别计数待确认；不得静默覆盖未同步记录，满额处置待联审 |
| 动作扩展 | 仅设备算法已支持的动作允许配置启用；新识别能力需独立评估算法/固件更新 |
| 时长目标 | 次数达标按实际次数≥目标次数；时长目标的有效时长与暂停计时口径为补充提案，须端云联审 |
| 任务取消 | 已接收取消后不再开始该任务；运动中取消、离线过期和剩余记录归档策略待端云联审 |

# 一级功能 1：开机绑定

## 1.1 首次启动

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 1.1.1 | 设备开机 | 完成设备启动和基础初始化 | P0 |
| 1.1.2 | 设备自检 | 检测基础模块状态 | P0 |
| 1.1.3 | 初始化状态提示 | 首次启动时展示初始化、自检结果和可继续条件；异常时给出恢复提示，衔接配网和运动入口 | P0 |

## 1.2 配网与绑定状态

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 1.2.1 | 近场配网配合 | 家长配置网络时接收Wi-Fi信息并尝试连接；设备反馈连接过程，承载方式按范围对齐项确认 | P0 |
| 1.2.2 | 配网进度与重试 | 配网中反馈正在连接、连接成功及已上线；按云端60秒超时口径反馈重试，区分密码错误和不支持网络 | P0 |
| 1.2.3 | 绑定状态确认 | 联网后获取设备与家庭绑定结果，区分待激活、绑定中、已绑定和失败；未确认归属前不将记录记入其他家庭 | P0 |
| 1.2.4 | 首次运动引导 | 绑定完成后依据首绑状态引导确认儿童并开始首次运动；已完成引导不重复打断入口 | P0 |
| 1.2.5 | 解绑状态恢复 | 接收有效解绑结果后恢复待激活，停止旧家庭任务和提醒，清除本地归属信息；未同步记录处置待确认，云端历史记录不由设备删除 | P0 |

## 1.3 当前儿童与数据归属

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 1.3.1 | 儿童信息同步 | 绑定后获取已授权儿童的最小必要标识、昵称和适用年龄段，供任务展示与运动归档；设备不创建儿童档案 | P0 |
| 1.3.2 | 当前儿童确认 | 开练前确认本次运动对应儿童；切换后刷新任务与成长显示，进行中的运动保留开始时的归属 | P0 |
| 1.3.3 | 儿童信息变更配合 | 接收档案删除、授权变化或数据重置结果后更新本地上下文与缓存显示，防止继续使用失效归属；离线清理时机待联审 | P0 |

# 一级功能 2：运动

## 2.1 快速运动

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 2.1.1 | 快速运动入口 | 儿童主动进入运动流程 | P0 |
| 2.1.2 | 运动项目选择 | 选择运动项目 | P0 |
| 2.1.3 | 本次目标确认 | 自主运动时确认设备支持的动作及次数或时长目标；家庭任务沿用已下发目标，不由设备重建任务编排 | P0 |
| 2.1.4 | 无任务运动引导 | 没有有效家庭任务时保留快速运动入口，提示选择支持的项目；缺少有效儿童归属时先引导确认 | P0 |

## 2.2 运动任务

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 2.2.1 | 运动任务接收 | 设备在线时接收新增与变更任务，启动或恢复联网时拉取当前家庭有效任务；仅接收可执行的动作与目标 | P0 |
| 2.2.2 | 今日任务展示 | 向当前儿童展示对应任务、动作、目标和时间，按时间排序；过期任务按已确认规则移除 | P0 |
| 2.2.3 | 任务开始 | 儿童选择有效任务后确认动作与目标，进入准备阶段，关联任务和本次运动记录 | P0 |
| 2.2.4 | 任务状态同步 | 接收并回传未开始、已提醒、进行中、已完成、未完成、已取消状态；断网时保存状态变更，恢复联网后按云端结果对齐 | P0 |
| 2.2.5 | 任务取消与移除 | 收到有效删除或取消后移除待执行入口并停止提醒；运动中取消及离线过期按待确认策略处理，保留已发生运动事实 | P0 |
| 2.2.6 | 不支持任务提示 | 动作或配置超出设备能力时明确不可执行，不误识别为其他动作，并回传不支持原因 | P0 |

## 2.3 运动准备与执行

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 2.3.1 | 运动准备提示 | 开始前提示动作与安全要点，检查有效儿童、摄像头授权及入镜条件，满足条件后进入倒计时 | P0 |
| 2.3.2 | 开始倒计时 | 儿童准备完成后显示并播报倒计时，结束时进入本地检测；取消准备不记录为已完成运动 | P0 |
| 2.3.3 | 实时运动进度 | 运动时展示有效次数、时长和目标进度，与3.1本地检测结果一致 | P0 |
| 2.3.4 | 中断与恢复 | 离画或用户暂停时提示原因并保留进度，满足恢复条件后继续；终止时记录中断原因，暂停计时口径待确认 | P0 |
| 2.3.5 | 达标与完成判断 | 按目标类型区分已完成与未完成；次数目标实际次数≥目标即达标，时长目标按待确认有效时长规则判断 | P0 |
| 2.3.6 | 主动结束与时长保护 | 支持儿童主动结束，按接收的单次时长上限停止或提示；保留实际结果，不因提前结束误记为达标 | P0 |

## 2.4 运动结果与记录

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 2.4.1 | 本次结果展示 | 完成或中断后展示动作、完成次数、完成时长、目标和是否达标，显示中断原因及数据同步状态 | P0 |
| 2.4.2 | 运动记录保存 | 结束时保存儿童归属、任务关联、动作、目标、实际次数/时长、开始结束时间、达标结果和中断原因，供4.3可靠同步 | P0 |
| 2.4.3 | 运动结果同步 | 在线时上报结构化记录，收到确认后更新为已同步；失败或断网时显示待同步，保留记录并进入补传 | P0 |
| 2.4.4 | 奖励结果展示 | 结果页显示云端确认的运动星和新纪录；离线时明确奖励待确认，避免将暂存结果展示为已结算 | P0 |
| 2.4.5 | 计数反馈配合 | 家长提交计数不准反馈时，设备仅提供关联记录的结构化计数、规则版本及必要错误信息；不上传原始图片或视频 | P0 |

## 2.5 成长激励

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 2.5.1 | 运动星反馈 | 达标后呈现确认的单次奖励及累计运动星；奖励按云端结算同步，同一记录重复补传不重复庆祝或增加余额 | P0 |
| 2.5.2 | 连续完成展示 | 展示当前儿童按自然日计算的连续达标天数；以云端确认值同步，离线旧值标明待更新 | P0 |
| 2.5.3 | 个人最好成绩展示 | 按动作展示个人最好成绩PR；次数类与时长类分别使用已确认规则，切换儿童后刷新归属 | P0 |
| 2.5.4 | 破纪录庆祝 | 收到本次运动的新纪录确认后提供短动画和鼓励语，重复确认不重复触发，结束后回到运动主线 | P0 |

## 2.6 运动提醒

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 2.6.1 | 提醒规则接收 | 接收任务提醒时间、重复规则及版本，在本地保存并按变更更新；取消任务时同步撤销提醒 | P0 |
| 2.6.2 | 本地提醒执行 | 有有效任务和缓存规则时到点提示儿童开始运动，断网仍可执行；任务已完成或取消后不再提醒 | P0 |
| 2.6.3 | 已提醒事件同步 | 触发提醒后保存事件并上报，将任务更新为已提醒；断网保存，联网后补传，避免重复计为提醒 | P0 |
| 2.6.4 | 免打扰执行 | 按生效规则抑制免打扰时段的声音提醒；云端默认21:00至次日7:00，具体设备规则随有效配置同步 | P0 |
| 2.6.5 | 提醒频次保护 | 同任务每天最多提醒3次、间隔至少10分钟，接收规则更新后执行；已完成任务不再催促 | P0 |

# 一级功能 3：运动检测与反馈

## 3.1 动作检测

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 3.1.1 | 人体检测 | 检测运动目标 | P0 |
| 3.1.2 | 动作识别 | 判断运动动作 | P0 |
| 3.1.3 | 动作计数 | 统计有效动作次数 | P0 |
| 3.1.4 | 有效动作判断 | 本地按当前动作的阶段、幅度与有效规则判断完整动作，过滤半动作和冷却期重复计数，支撑可信进度 | P0 |
| 3.1.5 | 离画状态反馈 | 按生效离画延时暂停检测并提示重新入镜，与2.3.4恢复流程衔接，不将目标缺失计为动作 | P0 |
| 3.1.6 | 动作错误提示 | 按可验证规则识别未达有效条件的动作并给予温和纠错；不输出医疗结论，不承诺算法未支持的质量评分 | P0 |

## 3.2 动作规则与配置

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 3.2.1 | 动作规则加载 | 开练前加载动作名称、计数方式、阶段、有效判定及安全提示；缺少有效规则时不给出可信计数承诺 | P0 |
| 3.2.2 | 识别参数同步 | 下次连接时接收计数冷却、半动作过滤、离画延时和幅度阈值；本次运动固定使用已确认规则版本，避免中途改变结果口径 | P0 |
| 3.2.3 | 规则版本缓存 | 按版本缓存动作规则，相同版本不重复下载；新版本无效时继续使用有效旧版并报告失败 | P0 |
| 3.2.4 | 动作配置回退 | 接收有效回退配置后切回指定有效版本，后续运动使用该版本；既有记录保留当次规则版本 | P0 |

## 3.3 陪伴反馈

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 3.3.1 | 倒计时语音 | 准备完成后按2.3.2播报倒计时，声音与屏幕进度一致；遵守当前音量和免打扰规则 | P0 |
| 3.3.2 | 运动鼓励语音 | 运动中依据实际进度提供适度鼓励，不遮挡有效计数或打断运动，不以未确认奖励诱导继续 | P0 |
| 3.3.3 | 完成庆祝反馈 | 确认运动完成后给出短庆祝动画与语音，区分达标完成和未完成；奖励结算与2.4.4分开表达 | P0 |
| 3.3.4 | 纠错与安全语音 | 动作无效、离画或达到安全限制时给出可理解提示，与3.1.6及运动恢复衔接，不羞辱儿童 | P0 |
| 3.3.5 | 反馈话术同步 | 接收有效倒计时、鼓励、庆祝和纠错话术版本并本地缓存，离线继续使用有效内容；不提供设备端话术编辑后台 | P0 |

| 4.2.3 | 远程音量执行 | 接收授权音量指令，在0~100范围内应用并确认实际结果，与4.1.1本地调整保持一致 | P0 |
| 4.2.4 | 摄像头开关配合 | 接收有效指令并执行采集开关；关闭时停止采集，必要时暂停运动；开启受本地授权与关闭约束，保持采集指示可见 | P0 |

## 4.3 离线运行与数据补传

| 编号 | 子功能 | 说明 | 优先级 |
|---|---|---|---|
| 4.3.1 | 离线运动执行 | 网络中断时继续本地人体检测、动作计数及反馈；有效儿童与规则缓存可用时支持快速运动或已缓存有效任务 | P0 |
| 4.3.2 | 本地记录缓存 | 断网时保存运动记录、任务状态变更和必要提醒事件；容量口径按待确认上限处理，满额不得静默丢弃未同步成果 | P0 |
| 4.3.3 | 联网自动补传 | 网络恢复后按记录唯一标识批量上报待同步数据，收到确认再移出待传队列；失败保留缓存 | P0 |
| 4.3.4 | 补传中断恢复 | 补传再次断网后保留未确认队列，下次从剩余记录继续；不将请求已发送等同云端已保存 | P0 |
