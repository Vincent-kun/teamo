0 定位与使用规则

本文定义逻辑页面、入口、页面职责、状态与功能映射，不定义视觉样式、按钮位置或输入硬件。逻辑页面可在屏幕能力评审后合并或分步呈现，不据此确定实体屏幕数量、比例或触控。设备面向6–15岁儿童，家长负责绑定、授权及管理；首页体现角色陪伴，同时保持任务与快速运动易进入。

本附录对应v0.4功能大纲。原功能编号、P0/P1与三/七动作范围不变。新增提议只写“Pending Review / 优先级TBD”，不能根据页面清单认定已加入MVP。已映射的页面继承功能优先级，表达形式仍需评审。

1 首次启动与日常启动

1.1 首次启动

适用于未绑定设备。恢复出厂后的再次绑定仅在恢复出厂功能获准后适用，不据此承诺已支持。

开机初始化 → 判断绑定/网络状态 → 未绑定时进入绑定引导 → 按已批准方案完成联网与家庭绑定 → 确认当前儿童 → 设备获得有效绑定状态 → 进入首页。

联网、扫码和绑定的顺序TBD：若绑定二维码需平台签发，设备必须先具备可用连接；若采用离线设备标识加家长端配网，步骤可以不同。本文不强制“先绑定后配网”，也不选择二维码或直连协议。

1.2 日常启动

开机初始化 → 恢复本地任务、记录和隐私状态 → 绑定有效进入首页；缺少儿童归属时进入身份确认；绑定失效进入绑定引导。断网不要求重新绑定，允许的缓存任务与本地运动仍可执行；后台待同步记录独立补传。

5 快速运动与家长任务

5.1 快速运动

首页 → 选择支持动作 → 确认自主次数目标 → 共用准备/倒计时/运动/结果流程。当前动作提议为开合跳、深蹲起、高抬腿；选择不支持动作不得伪装可开始。允许目标范围及操作输入TBD。自主结果标记自主来源，不显示为家长布置任务。

5.2 我的任务

列表至少让儿童看懂动作、目标和状态；详情提供来源和执行条件。任务名称、创建时间是否必须在设备显示，TBD；不能为了展示字段增加复杂页面。收到任务只更新任务状态/入口，不自动开启摄像头或跳过儿童开始确认。

未开始 → 进行中 → 达标完成或提前结束。同步状态与任务执行状态分别显示：已保存待同步不等于任务未完成，提前结束不等于达标。撤销/过期/重复任务按3.1有效规则处理，细节TBD。

目标、实际与状态来自同一设备运动事实；页面只呈现与触发操作。返回页面不自行重建记录、改目标或递增次数。

7 独立姿态检测：候选边界

用户本轮提议将其作为独立检测工具，需区别于已存在的“运动准备中人体检测/站位引导”和非运动体态陪伴。现有4.1.1与3.2.2只支持明确运动流程中的准备能力，不能直接证明独立检测已进入MVP。

提议可复用依据未决内容
人体在场检测、站位提示、退出4.1.1、3.2.2、2.2.2独立采集场景、授权、退出关闭规则是否纳入
骨骼关键点显示无已冻结显示形式显示必要性、屏幕可理解性、儿童隐私与资源；Pending Review
动作辅助提示4.2与5.1仅对已验证动作有效如何选择动作和判断提示；不扩展未验证纠正能力

不做医疗体态分析、身材评价或健康评分。若获准，必须明确采集开始/停止意图及隐私守卫；退出关闭采集、不持久化原始帧。PAGE-09目前不计入已映射MVP页面承诺。

9 信息架构与评审问题

日常首页 → 快速运动 / 我的任务 / 设置。

快速运动与任务 → 共用运动准备 → 倒计时 → 运动中 ↔ 暂停/重新准备 → 结束保存 → 结果 → 首页；同步独立进行。

首次未绑定 → 绑定与联网引导 → 当前儿童确认 → 首页。

独立姿态检测、声音控制、恢复出厂、检查更新为待评审分支，未加入当前默认入口。

问题冻结前需要结论
绑定方案及联网先后依赖QR是否采用、由谁提供凭据、过期/失败恢复及配网端
页面承载与操作方式屏幕与远距可读性、触控/按键等输入、逻辑页面合并范围
独立姿态工具是否纳入与运动准备/体态陪伴的区别、骨架显示是否需要
首页今日摘要是否需要任务/完成的聚合口径与端间一致性
设置新增提议的范围声音、名称/SN、出厂恢复、更新入口及家长授权
页面对既有角色/三动作边界继承v0.4待决结论，不通过UE另行冻结
