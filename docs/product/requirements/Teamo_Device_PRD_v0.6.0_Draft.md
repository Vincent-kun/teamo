# 1 产品定位与目标

继承功能大纲 v0.5.2 §0.4，本文档不重新定义产品。

- 设备帮助 6–15 岁儿童完成家庭运动，家长通过 APP/小程序布置任务、查看结果。
- 设备端负责运动当下的交互、识别、反馈、记录及同步；APP 负责家长管理；平台负责传递、权限关系与统一服务（见 §12 跨端职责矩阵，v0.5.2）。
- 一次运动主线：查看任务或选择运动 → 确认目标 → 准备 → 倒计时 → 识别计数与反馈 → 完成或提前结束 → 保存结果 → 同步家长端。
- 当前 MVP 动作提议为开合跳、深蹲起、高抬腿三动作；三动作是演示切片还是产品范围调整仍需确认（OQ-01），本文档不裁决。

# 6 全局业务约束

继承 v0.5.2 §8.3 与 UE IA v0.3.1 §5「保留的业务约束」，为准入条件，不作为独立功能点计数：

- 儿童原始摄像帧不持久化，不写入记录、日志或缓存，不上传持久化。
- 未授权、关闭、撤权或状态未知禁止采集；远程任务不绕过本地关闭。
- 不完整、重复、不确定事件不计；低置信度不作确定纠错。
- 不修改家长目标；提前结束不伪称达标；返回不重建结果。
- 未保存不称已记录，发送完成不称业务接收；同步不阻断允许的本地运动。
- 断网不解绑；重启恢复真实事实，不自动续计。
- 无广告、儿童充值、陌生人社交或公开身体数据；不开放聊天、医疗/身材/姿态评分、视频监控。

# 8 核心用户流程（User Flow）

[NEW] 以下流程为对既有 Function / State / PAGE 的组织，不设计新流程。每步均引用已有编号；候选能力（7.2.4–7.2.7、3.1.5/3.1.6 等）不作为流程必经步骤。

## Flow A：首次使用流程

触发条件：用户第一次打开设备。

流程：

```
设备启动
↓
初始化检查
↓
绑定状态确认
↓
儿童身份确认
↓
进入设备首页
```

|步骤|用户行为|设备行为|关联Function|State|
|-|-|-|-|-|
|1 设备启动|上电|启动软件并验证必要运行条件|1.1.1|开机初始化（v0.5.2 §11.2；UE INIT 标签不含开机）|
|2 初始化检查|等待/查看提示|通过后进入待机；失败给出重试/返回/重启入口|1.1.1、1.2.2|开机初始化 / 异常|
|3 绑定状态确认|家长完成联网与绑定（方案 TBD，OQ-13）|提供联网配置、读取并确认绑定关系；失败说明真实原因|7.1.1、7.1.2、7.2.3|绑定：未绑定→等待→处理中→成功|
|4 儿童身份确认|家长确认当前儿童|确认绑定关系及当前儿童身份，不默认人脸识别|7.2.3|儿童待确认→确认完成|
|5 进入设备首页|儿童查看可用状态与入口|呈现角色状态、运动入口与必要设备/网络/隐私状态|2.1.1、2.1.2、2.2.1|待机（PAGE-01）|

说明：7.2.4 首次绑定引导、7.2.5–7.2.7 二维码及帮助为待评审候选（CH-11–14），不作为本流程已确认步骤；绑定方案未决前本流程的步骤 3 承载方式 TBD（OQ-13）。

```

↓

↓

↓

↓

↓
实时反馈
↓
结束
↓

↓

↓

```

|步骤|用户行为|设备行为|关联Function|State / PAGE|
|-|-|-|-|-|
|进入运动入口|在首页选择自主运动|提供运动入口与可用状态|2.1.1|待机 / PAGE-01|
|选择自主运动|选择支持动作|呈现可选动作（三动作 MVP 提议）|2.1.1、3.1.4|INIT / PAGE-02|
|确认动作与目标|确认允许目标|确认动作及目标，不混淆家长任务|3.1.4|INIT / PAGE-02|
|动作说明|查看说明|提供经审核、儿童可理解的说明；可跳过规则 TBD|3.2.1|READY / PAGE-04|
|入镜准备|按提示调整站位|依据识别结果引导；隐私允许才识别准备|3.2.2、4.1.1、8.1.1|READY / PAGE-04|
|开始确认|明确开始|检查开始条件，满足后倒计时|3.2.3|READY→COUNTDOWN / PAGE-05|
|倒计时|等待|复核条件；不计数；离画回准备|3.2.3、4.1.1|COUNTDOWN / PAGE-05|
|运动识别|执行动作|仅累计完整有效周期；不确定事件不计|4.1.2、4.1.3、4.2.1–4.2.3|RUNNING / PAGE-06|
|实时反馈|查看进度|呈现已确认次数与调整提示|5.1.1、5.1.2；2.1.2 角色回应|RUNNING / PAGE-06|
|（分支）暂停/继续|暂停或离画后继续|保留已确认成绩；恢复重查隐私与准备；再倒计时 TBD|3.3.1、3.3.2|PAUSED→READY / PAGE-06→PAGE-04|
|结束|达标或提前结束|停止采集，保留真实未完成状态|3.3.3|FINISHED / PAGE-06→07|
|结果展示|查看结果|显示动作、目标、实际次数、用时与结束状态|5.1.3、5.2.1|FINISHED / PAGE-07|
|保存|—|生成唯一记录并本地保存；失败如实说明|6.1.1、6.1.2、6.2.1、6.2.3|FINISHED→SAVED|
|同步|—|上传并按平台业务确认更新状态；失败沿用原标识补传|6.3.1、6.3.2；5.2.2 提示|SYNCING→SYNCED（后台，不阻断本地运动）|

关联 State：READY、COUNTDOWN、RUNNING、PAUSED（分支）、FINISHED、SAVED、SYNCING、SYNCED；自主上下文确认对应 INIT（记录创建时机 TBD，OQ-08）。

## Flow D：异常恢复流程

### 网络异常

```
运动开始
↓
网络断开
↓
继续本地运动
↓
本地保存
↓
恢复网络
↓
补传结果
```

|步骤|设备行为|关联Function|State|
|-|-|-|-|
|网络断开|显示离线状态与当前可用能力；不阻断允许的本地运动|7.1.2|在线/离线（独立维度）|

# 11 隐私与安全边界

必须继承 v0.5.2 §8.3 与 UE IA v0.3.1 §5，本文档不放宽、不新增授权能力。

## 支持：

- 动作识别（三动作有效计数；4.1.2、4.2.x）
