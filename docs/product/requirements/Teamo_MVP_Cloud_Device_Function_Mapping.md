# Teamo MVP 云端-设备端功能对应关系表 v0.1

## 用途

检查云端功能是否有设备能力支撑，只做功能归属。家长侧入口见[多端范围定义](Teamo_MVP_Multi_End_Function_Scope.md)。

| 业务模块 | 设备端功能 | 云端功能 | 备注 |
|---|---|---|---|
| 账号家庭与儿童 | 确认当前儿童、接收必要档案信息 | 账号家庭与档案管理 | 创建编辑入口在小程序 |
| 设备绑定 | 初始化、配网、连接、绑定状态提示 | 设备管理与归属管理 | 小程序发起绑定 |
| 任务 | 接收、展示、执行、反馈任务情况 | 任务管理 | 小程序创建；设备支持自主运动 |
| 运动 | 本地识别、计数、执行、结果反馈 | 运动记录管理 | 视频不上云、不持久化 |
| 记录同步 | 保存必要结果、离线缓存、联网同步 | 记录接收与存储管理 | 不定义容量、字段或重试方式 |
| 激励 | 展示奖励与成长反馈 | 激励数据管理与同步 | 不设计运动星规则 |
| 消息提醒 | 向儿童提供任务提醒 | 向家长消息触达 | 两种使用对象 |
| 设备设置与状态 | 应用设置、展示并同步设备状态 | 设置与设备状态管理 | 小程序提供操作入口 |
| 升级 | 执行升级并反馈结果 | OTA与版本管理 | 不定义技术流程 |
| 隐私与安全 | 本地识别、采集提示、隐私控制 | 必要业务数据安全管理 | 小程序承担授权入口 |
| 故障维护 | 必要异常日志记录与平台同步 | 故障信息管理与查询 | 保留现有功能，最小化数据 |

## 检查结果

上述核心模块均有对应职责。账号创建、家庭管理、任务编排和历史查询无需在设备上重复建设；设备承担必要的儿童确认、执行与反馈。原云端稿混合小程序入口和云端管理职责，按此表区分，但不直接改写源稿。
