MVP 设备端软件功能大纲 v0.3

日期：2026-10-12 · 状态：评审稿 · 负责人：设备端软件产品负责人（待确认）

用途：先确认设备有哪些功能、每项功能做什么，以及MVP范围。

设备帮助6–15岁儿童完成家庭运动，家长通过APP/小程序布置任务、查看结果。设备端负责运动当下的交互、识别、反馈、记录及同步。

本稿以开合跳、深蹲起、高抬腿为当前MVP动作提议。现行整体PRD包含七动作，三动作是演示切片还是产品范围调整，仍需确认。P0为本稿MVP必需项；P1为后续候选；P2暂不列具体功能。本文未冻结。

功能总览

一级功能二级功能主要输出
1 设备启动与运行管理启动与运行；状态与异常设备可用状态、恢复结果及故障提示
2 运动入口与操作运动入口与角色回应；状态提示与操作确认清晰入口、可操作信息与角色回应
3 运动任务与执行任务接收与查看；运动准备与开始；暂停、继续与结束可执行目标及开始、暂停、恢复、结束状态
4 动作识别与计数识别状态与有效计数；三种动作识别三种动作的有效次数及识别状态
5 运动反馈与结果展示即时反馈；结果查看与保存提示当前进度、调整提示及真实运动结果
6 运动记录与同步运动记录；本地保存与记录恢复；结果同步可追溯记录、保存结果及同步状态
7 联网与使用者管理网络连接与状态提示；平台状态同步与使用者确认连接状态、通信确认及当前儿童
8 隐私控制与数据管理摄像头使用控制；数据权限与提醒控制可见、可停止的采集和受控数据使用

一次运动：查看任务或选择运动 → 确认目标 → 准备 → 倒计时 → 识别计数与反馈 → 完成或提前结束 → 保存结果 → 同步家长端。

本版检查结论：功能名称表达设备行为；目标和约束单独说明；同一业务行为只有一个主要归属，其他模块提供输入或呈现结果。

下面按“一级功能 → 二级功能 → 功能点”展开，使用1.1.1这样的数字编号。具体页面、协议、算法和测试指标留到详细需求阶段。

1 设备启动与运行管理

1.1 启动与运行

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
1.1.1开机与初始化启动软件并验证必要运行条件，进入可用或明确异常状态。让家庭知道设备能否开始使用。P0启动时长待确认
1.1.2启动状态恢复重启后读取已保存的任务、结果和隐私状态，决定进入待机、恢复提示或异常状态；记录的读取与恢复由6.2.2负责。重启后回到正确状态，不自动续计或伪称完成。P0恢复进入哪个状态待确认

1.2 状态与异常

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
1.2.1设备运行状态管理统一维护当前运行状态和允许的操作；运动过程的暂停、恢复与结束由第3章定义。状态一致，避免同一操作在不同入口产生冲突。P0—
1.2.2设备故障处理处理启动失败、运行服务不可用等设备级故障，给出重试、返回或重启入口；识别异常由4.1.3判断。故障时能够理解原因并恢复使用。P0故障范围与恢复时限待确认
1.2.3软件版本查看提供当前设备软件版本。便于核对设备版本和定位兼容问题。P0—
1.2.4故障信息记录记录必要的故障原因和发生时间，供诊断使用。故障可定位、可复盘。P0日志内容与保存周期待确认
1.2.5设备重启提供必要重启操作，重启后按1.1.2恢复状态。无法正常使用时有恢复入口。P0重启触发方式待确认

2 运动入口与操作

2.1 运动入口与角色回应

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
2.1.1运动入口提供任务与自主运动入口，显示必要可用状态。减少寻找入口和开练阻力。P0—
2.1.2角色表情回应依据运动状态显示固定角色表情；是否鼓励及提示内容由第5章定义。运动中获得一致且适度的角色回应。P0表情事件与资源待确认

2.2 状态提示与操作确认

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
2.2.1设备状态提示呈现设备不可用、操作不可执行等通用状态；任务内容、实时成绩和结束结果分别由第3章和第5章定义。知道设备当前是否可用，以及怎样处理问题。P0表达方式待确认
2.2.2操作接收与确认接收选择、开始、取消、暂停、继续、结束及返回操作，并告知是否接受；各操作业务结果由所属功能负责。清楚操作是否生效。P0触控、按键或其他输入方式待确认

3 运动任务与执行

3.1 任务接收与查看

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
3.1.1接收与检查任务接收家长任务，校验儿童归属、支持动作、目标及有效条件。收到可执行而非无效任务。P0任务检查规则待确认
3.1.2确认任务已接收保存成功后确认接收；拒绝说明原因，重复任务不新增。家长知道任务是否真实送达。P0—
3.1.3任务展示与状态提供动作、目标与来源，区分未开始、进行中、已结束和撤销。儿童明白为什么做、做多少。P0任务状态及撤销规则待确认
3.1.4动作与目标确认执行任务时确认已下发动作和目标；自主运动时选择支持动作及允许目标，不擅自修改家长任务。运动目标清楚，自主运动与家长任务不混淆。P0自主目标范围待确认

3.2 运动准备与开始

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
3.2.1动作说明开始前提供经审核、儿童可理解的动作与安全说明。减少不理解动作造成的失败。P0媒体形态/可跳过规则待确认
3.2.2入镜准备引导根据第4章识别结果提示调整站位；准备不足时不开始运动。知道如何站好，准备完成后再开练。P0准备完成条件待确认
3.2.3开始确认与倒计时儿童明确开始且准备满足后倒计时，结束再检查开始条件。有时间准备，避免突然计数。P0输入方式待确认

3.3 暂停、继续与结束

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
3.3.1暂停与成绩保留主动暂停或离画/识别异常时停止新增成绩，保留已确认次数。已完成努力不因中断消失。P0—
3.3.2恢复运动重新检查隐私和准备，明确恢复后从已确认成绩继续。安全且连贯地继续运动。P0恢复时重新判断动作起点；恢复确认方式待确认
3.3.3达标与提前结束达标停止确认动作；主动结束保留实际与真实未完成状态。不强迫继续，不伪造达标。P0自动超时结束规则待确认

4 动作识别与计数

4.1 识别状态与有效计数

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
4.1.1人体与画面可用性检测判断是否有人、身体是否完整及画面是否满足识别条件，输出准备状态和原因；引导由3.2.2负责。避免在看不清动作时开始计数。P0多人处理及适用距离待确认
4.1.2有效动作计数依据审核规则仅累计完整有效周期，未完成、重复或不确定事件不计。孩子和家长得到可信成绩。P0阈值待确认
4.1.3识别异常判定区分无人、遮挡/画面不足、识别不确定与识别不可用，交给流程和反馈处理。知道如何调整，而非被错误指责。P0—

4.2 三种动作识别

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
4.2.1开合跳动作判定判断并拢、打开、回收是否形成完整有效周期，供4.1.2累计次数。完整开合跳被可信记录。P0有效幅度与规则待确认
4.2.2深蹲起动作判定判断站立、有效下蹲、回站立是否形成完整周期，供4.1.2累计次数。完整深蹲被可信记录。P0安全与有效幅度规则待确认
4.2.3高抬腿动作判定判断有效抬腿与落下事件，按统一左右侧规则供4.1.2累计次数。目标与实际成绩使用一致口径。P0单侧一次或双侧一轮待确认

8 隐私控制与数据管理

8.1 摄像头使用控制

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
8.1.1隐私检查与采集阻断隐私关闭、授权不足或状态未知时禁止采集和开始识别。家长边界可控且可解释。P0—
8.1.2摄像头状态提示与关闭显示真实采集状态；运动退出或授权撤销后停止采集，不能通过远程任务绕过本地关闭状态。知道摄像头是否工作，并能停止采集。P0状态提示方式与撤权响应待确认

8.2 数据权限与提醒控制

编号功能点做什么 / 产生什么结果用户价值优先级待确认内容
8.2.2数据访问与删除请求处理在设备端执行访问权限，并响应撤权、记录删除和解除绑定相关数据处理请求。可管理设备数据的使用和清理。P0删除范围与离线响应待确认
8.2.3提醒时段与频率控制按已设定时段和频率限制输出提醒，抑制重复提示；提示内容由第5章提供。减少重复催促和夜间打扰。P0设置责任端、时段与频率待确认

8.3 贯穿全部功能的约束

以下为准入条件，不作为独立功能点计数：儿童原始摄像帧不持久化，不写入记录、日志或缓存，不上传持久化；隐私关闭或状态未知不得采集；低置信度不作确定纠错；提前结束不伪称达标；无广告、儿童充值、陌生人社交或公开身体数据。记录、识别和反馈功能均须满足这些约束。

9 后续功能与范围待确认

9.1 P1后续候选

功能做什么范围说明
更多运动项目从已有动作池增加经验证的动作与整体PRD七动作范围一起确认
运动训练建议根据真实记录及审核规则提供受限建议不自由生成儿童运动处方
个性化成长展示个人进步、长期成长与徽章基础运动星、个人最好成绩是否属于P0，单独确认
内容与语音陪练用运动相关内容帮助开始和坚持不发展为开放聊天或独立游戏循环

P2暂不分配。学校授权任务、独立体态观察、软件升级（OTA）和远程诊断继续保留原需求追踪，本轮范围及优先级待确认。

9.2 本轮需要确认的功能问题

问题对功能范围的影响
三动作是本轮演示范围还是产品MVP范围？决定其余四动作放在哪里，不能静默删减原PRD
儿童怎样开始、暂停、恢复和结束？决定基本操作输入；触控、按键或其他方式未定
高抬腿是一侧一次还是两侧一轮？决定目标及结果计次口径
多儿童切换、多人入镜怎样处理？决定任务与成绩归属
基础运动星、个人最好成绩是否纳入P0？决定完成反馈与成长边界
是否必须支持OTA？决定设备维护是否属于当前交付必需能力
动作说明能否跳过；中断多久结束？决定开始安全前置与暂停后结束行为
记录保存多久，撤权和删除如何响应？决定恢复与数据管理边界；儿童原始视频不保存

原始儿童摄像帧不持久化；隐私关闭或状态未知不能采集。家长端负责任务创建、权限和查看，设备负责真实运动结果，平台负责传递与统一记录。
