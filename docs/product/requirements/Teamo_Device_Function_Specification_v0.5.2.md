### 0.4 产品定位、MVP说明与功能总览

| 一级功能 | 二级功能 | 主要输出 |
|---|---|---|
| 1 设备启动与运行管理 | 启动与运行；状态与异常 | 设备可用状态、恢复结果及故障提示 |
| 2 运动入口与操作 | 运动入口与角色回应；状态提示与操作确认 | 清晰入口、可操作信息与角色回应 |
| 3 运动任务与执行 | 任务接收与查看；运动准备与开始；暂停、继续与结束 | 可执行目标及开始、暂停、恢复、结束状态 |
| 4 动作识别与计数 | 识别状态与有效计数；三种动作识别；独立动作辅助检测（待评审） | 三种动作的有效次数及识别状态 |
| 5 运动反馈与结果展示 | 即时反馈；结果查看与保存提示 | 当前进度、调整提示及真实运动结果 |
| 6 运动记录与同步 | 运动记录；本地保存与记录恢复；结果同步 | 可追溯记录、保存结果及同步状态 |
| 7 联网与使用者管理 | 网络连接与状态提示；平台状态同步与使用者确认 | 连接状态、通信确认及当前儿童 |
| 8 隐私控制与数据管理 | 摄像头使用控制；数据权限与提醒控制 | 可见、可停止的采集和受控数据使用 |

一次运动：查看任务或选择运动 → 确认目标 → 准备 → 倒计时 → 识别计数与反馈 → 完成或提前结束 → 保存结果 → 同步家长端。

本版检查结论：功能名称表达设备行为；目标和约束单独说明；同一业务行为只有一个主要归属，其他模块提供输入或呈现结果。

下面按“一级功能 → 二级功能 → 功能点”展开，使用1.1.1这样的数字编号。具体页面、协议、算法和测试指标留到详细需求阶段。

## 11 状态模型

### 11.1 状态关系

开机初始化 → 待机 → 任务准备（任务或自主目标）→ 运动准备 → 倒计时 → 运动中 → 结束 → 结果展示 → 待机。

运动中 → 暂停 → 重新运动准备 → 继续运动；恢复是否再次倒计时待确认。暂停可主动结束。“同步”是已保存记录的独立状态，可与结果展示、待机或新运动并存；“异常”是从相应状态进入的分支，不是同步后的必经步骤。下表是业务状态候选，不冻结技术实现。

### 11.2 状态规则

| 状态 | 进入条件 | 允许操作 | 禁止操作 | 退出条件 |
|---|---|---|---|---|
| 开机初始化 | 上电或重启 | 等待、查看提示；故障时约定重试 | 计数、隐私未明时采集、伪称恢复完成 | 验证通过进入待机/恢复提示，失败进异常 |
| 待机 | 启动就绪或退出运动 | 查看任务、自主入口、必要维护 | 暗中运动采集、生成完成结果 | 选任务/目标进任务准备，故障进异常 |
| 任务准备 | 已选任务或自主目标 | 查看确认目标、返回 | 静默修改家长目标，未接收却称接收 | 归属和目标有效进运动准备，取消回待机 |
| 运动准备 | 目标明确，隐私允许才识别准备 | 查看动作说明、调整站位、返回 | 准备不足开练、累计成绩 | 明确开始且条件满足进倒计时；恢复规则待确认 |
| 倒计时 | 开始意愿明确且准备满足 | 等待、取消 | 未结束计数、守卫不满足强行运动 | 完成再检查后进运动中；离画回准备，隐私问题阻断 |
| 运动中 | 正常开始或恢复获准 | 运动、查看进度、暂停、提前结束 | 重复/不确定事件计数，绕过隐私关闭，静默换目标 | 达标/结束进结束；暂停触发进暂停；故障按异常规则 |
| 暂停 | 主动暂停或已判定需暂停 | 查看成绩、选择继续或结束 | 新增成绩，清零努力，绕过准备继续 | 继续回运动准备，结束进结束；超时待确认 |
| 结束 | 达标、主动结束或已确认中断规则 | 等待生成保存、保存失败重试 | 新增计数，保存前称已保存 | 保存成功进结果展示；失败进入相应异常处理 |
| 结果展示 | 有真实已保存结果 | 查看结果、返回待机 | 未达标称完成，未同步称家长已收到 | 返回待机；同步独立继续 |
| 同步（记录状态） | 已保存且未获平台业务确认 | 查看状态、按条件补传 | 重建同一结果，发送完成当接收成功，阻断允许本地运动 | 平台确认进已同步；失败待补传 |
| 异常（分支） | 设备、识别、权限或保存问题 | 查看原因、按所属功能重试/返回/重启 | 隐瞒异常，伪造完成，条件未恢复计数 | 守卫恢复后回适用状态；不可恢复处理待确认 |

1.2.1维护状态一致性；第3章定义运动转移；第4章输出成绩事实；第6章保存/同步；第8章提供隐私守卫。同一运动不由不同模块维护冲突状态。
