# Decision Log

## Decision TEAMO-CLOUD-ALIGNMENT-001

Date: 2026-10-13

Problem: 归档导出稿与仓库现行大纲同为设备端文档，但编号含义不同，直接合并会覆盖现行编号。

Context: 用户给定v1.0导出稿和云端大纲，要求保留编号并输出v1.1；仓库另有XMind源图大纲v1.1.0。

Options Considered: 覆盖现行稿；以导出稿为基线生成独立补充稿。

Decision: 采用独立稳定路径，以导出稿v1.0.0为基线生成v1.1.0评审稿，明确两个文档用途；待负责人确认后再合并需求。

Reason: 保留全部原编号，避免将不同来源的同号功能静默替换。

Impact: 新增范围均为待评审提案；不批准MVP扩容、硬件条件或架构变更。

Owner: 待确认（项目协调：魏子奇）。

Status: Proposed

Evidence: 用户修改提示词、两份原始输入、DOCUMENT_REGISTER.md及备份manifest.json。

## Decision TEAMO-CLOUD-ALIGNMENT-002

Date: 2026-10-13

Problem: 云端输入含动作、年龄、硬件及隐私执行条件差异。

Context: 项目权威规则禁止静默覆盖现行要求。

Options Considered: 原样复制云端所有P0；仅映射设备行为并标记条件/冲突。

Decision: 建议采用本文差异表的限制条件，保留权威边界，冲突待负责人联审。

Reason: 补充设备执行闭环，不将云端原始输入提升为产品批准证据。

Impact: 动作、配网、升级、缓存及摄像头相关功能需后续联审。

Owner: 待确认（产品及硬件/算法负责人）。

Status: Proposed

Evidence: 云端2.1、2.4、2.5、3.1、3.4、6.2及产品定义定位与边界规范。
