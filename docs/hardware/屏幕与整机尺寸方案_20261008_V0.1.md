# 屏幕选型与整机尺寸｜魏子奇讨论方案 V0.1

> **2026-10-09用户补充：开发板仅是开发平台，最终产品自研主板。下文P4退出产品尺寸比较，P1–P3的Core＋载板属于历史计算案例，不代表已选产品架构。**

> 2026-10-08。用途：先做有型号、有排布、有尺寸预算的方案，再找技术负责人讨论。以下是提案，不是采购或PCB冻结。外形统一宽W×深D×高H；屏与板的二维规格为宽×高。

## 1. 我建议你带哪几套方案去讨论

### 为什么不能先锁60×90

沿用此前误差假设，55mm屏板宽轴需要55＋0.20部件预算＋1.00双侧间隙＋4.00双侧壁厚＋0.30内腔偏差＝**60.50mm外宽**；60mm不足0.50mm，且这还没算曲面/屏槽/FPC。若圆屏板55mm高、相机24mm高且同一前脸上下排放，再预留4mm间隔和5.5mm边界预算，需至少**88.50mm外高**。90mm理论只剩1.50mm，不能同时容纳任意大圆角、底部声孔和滑盖机构。

因此圆屏主方案放大到P2；方屏P1则主要受前后板、电池、线材以及摄像头支架约束。原57.77×35.70×93.47只是比例起点，不继续把它当硬件可装结论。

## 3. 三轴怎么算：先排布，再算截面

形态建议：竖向扁胶囊、局部平前脸、顶部小圆角、平底、前后分壳、独立内支架。**不采用整面半圆端部吞掉屏角的纯体育场轮廓。**圆角大小待真实内表面模型确定。

前脸相机在上、屏在中下；载板平行前脸靠后中部；电池靠后下部。相机与电池尽量错开深度热区。扬声器、天线、4G/SIM、电源、USB-C与线材仍竞争同一空间，不因方案图中有框就声称全部装得下。

本轮设计占位：

| 项目 | 真实输入 | 设计占位/假设，须技术负责人评审 |
|---|---|---|
| 核心板 | Core 30×30×5.50 | 载板先占42×55；厚度总占位10mm，包含核心板/载板与双面器件；不是已设计板框 |
| Pico Max | 21×72板框 | 板与连接器完整深度先占25mm；要量RJ45、USB、排针、线头与散热；数值不来自厂家完整T |
| 相机B | 25×24板，前侧16.60等局部标注 | 完整支架/镜头/遮挡深度先占24mm，额外出线3mm；滑盖加高另核 |
| 2000mAh参考电池 | 36×60×7 | 深度算7.2mm，其中0.2为未知公差预算；膨胀、绝缘、温度及固定要求必须按供应商再加 |
| ESP屏板 | 55×55；T未知 | 暂占13mm。实际总厚或线头超过此值，P2立即重算，不填假T进器件规格 |
| 1.69触控屏 | 33.13×41.13 | 厚度预算9.5mm，不冒称实际完整T |
| 打印与装配 | 尚未校准 | 壁厚2mm/侧、内腔向内偏差0.3mm总计、普通间隙0.5mm/侧；光学定位另定 |

核心板出处：[Core1106厂家尺寸/接口](https://www.luckfox.com/Core1106)。开发板出处：[Pico Pro/Max](https://www.luckfox.com/EN-Luckfox-Pico-Pro)。相机出处：[MIS5001(B)](https://www.luckfox.com/MIS5001-5MP-Camera-B)。设计占位不能替代这些器件的正式机械图。

深度截面预算（同截面才相加）：

```text
P1屏截面 = 9.5屏 +1屏板间隔 +10载板总包络 +1板电池间隔
           +7.2电池 +3线材/固定 +4.3壳壁/内腔偏差 =36.0mm
选择D=38.0，预留2.0mm未分配预算。

P2屏截面 =13屏板预算 +1 +10 +1 +7.2 +3 +4.3 =39.5mm
选择D=42.0，预留2.5mm未分配预算。

P3屏截面 =2.16裸屏含演示超差 +1 +10 +1 +7.2 +3 +4.3 =28.66mm
相机截面 =24安装占位 +3出线 +4.3壳预算 =31.3mm
选择D=35.0；相机后方不得再随意叠电池/整块主板。

P4屏截面 =9.5 +1 +25开发板预算 +1 +7.2 +3 +4.3 =51.0mm
P4主提案取D=52.0，保留1.0mm未分配预算。缩至48mm才需要错层。
拟采用屏+开发板=42.8mm、电池放开发板后下独立凹位/错层；D=48只适用于实际错层可实现。
若错层不可行，D至少按51mm预算放大，黄金比例联动为82.52×51×133.52mm。
```

**P4主提案是52mm深度；48mm版仅是错层可行时的缩小方向，不能为外观压缩电池。**更稳妥的工程验证可以外置开发板/电池，不宣称同尺寸通电样机已完成。

宽高先检验同层排布：P1前脸41.13＋24＋4＋5.5＝74.63mm；P2为88.50mm；P3为83.09mm。P4主板与相机若同层上下排，72＋24＋4＋5.5＝105.50mm。所有提议高均不被这些单轴必要条件排除，但曲面、安装柱和机构仍须局部验证。

黄金比例：φ=(1+√5)/2；W=max(Wmin, φ·Dmin, Hmin/φ)，D=W/φ，H=φ·W。本轮先选择讨论深度35/38/42/52，再得到表中宽高。大圆角、底座、滑盖或供应商新板改变下限时，重新联动。尺寸两位小数只是计算显示，不是3D打印公差。

## 4. 电气与成本也是屏幕选型条件

- 方屏240×280与圆屏360×360像素比约1.93，RGB565一帧分别134400/259200字节；30fps纯像素数据分别约32.26/62.21Mbit/s，未计指令、总线开销。此为理论预算，不是SPI实际刷新率；实际可局部刷新或降低fps，需按UE测试。
- P2增加ESP屏板和板间协议，但避免把所有圆屏驱动移植问题直接压在视觉主控上。单价增加多少要问指定SKU含税报价，不用美元网页价给人民币总成本盖章。
- P3裸屏尺寸小，却可能增加FPC转接、电源、驱动与触控设计费。按“物料＋载板＋适配＋打样返工＋交期”比较，不能只看屏单价。
- 电池续航按真实平均功率算：t≈3.7×容量Ah×系统可用系数η/Pavg。2000mAh只是7.4Wh标称；例如η=0.8、Pavg=3W时约1.97h，这是演示假设，未测量不承诺续航。
- 4G首版是否必须内置待产品/技术确认；包含时要补SIM、天线、瞬态电流、DC/DC和净空，不能只塞17.7×15.8模组框。本稿尺寸没有完成内置4G验证。

## 5. 你可以直接这样开讨论会

开场：“我带了P1方屏核心板与P2圆屏双处理器两套主方案。机身暂提61.49×38×99.49和67.96×42×109.96，来源是实际器件平面尺寸加设计深度预算；请今天定主控路线与屏驱动路线，再把载板/线头/电池真实尺寸替换进去。”

| 今天要讨论的问题 | 你的初步提案 | 要拿到的结论/证据 |
|---|---|---|
| 圆屏是不是必须、触控是否首版必需 | P1带触控；P2圆屏带独立UI | 产品认可的屏形与交互，方屏是否允许作为MVP |
| RV1106B合作方案能提供什么板 | 不预设等同Core1106 | 指定板型号/图纸、RAM、接口、SDK、技术支持与交期 |
| 屏驱动谁负责、多久可以亮屏跑UE | P1 SPI移植；P2 ESP端UI＋UART协议 | 负责人、现成工程、目标帧率、相机/模型并行验证安排 |
| 载板42×55×10占位是否足够 | 作为占位提案，不作为下发PCB板框 | 器件预布局、双面限高、USB/FPC朝向、散热和电源预算 |
| P2屏整板13mm/P4开发板25mm预算可否成立 | 先量实物与线头 | 完整机械图/卡尺记录；超预算重算 |
| 电池2000mAh是否合适 | 先用尺寸参考，找国内成熟料 | 指定料号、保护/NTC、连续/峰值电流、容量、热要求、交期 |
| 4G是否进入首版 | 单独做包含/不包含分支 | 产品决定与天线/供电/空间增量，不能默默删4G |
| 谁家的方案团队用过 | 公开候选不冒称合作方 | 公司、联系人、指定SKU含税BOM、SDK经验与可复用代码 |
