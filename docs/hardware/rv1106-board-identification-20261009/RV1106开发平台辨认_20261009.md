## 3. 自研产品主板应从平台取走什么

1. 精确SoC后缀、RAM/存储、SDK/BSP版本和算法模型验证记录。

2. 相机sensor/ISP配置、屏驱动/总线能力、音频和网络的并行结果。

3. 可用原理图、电源树、关键器件与参考PCB布局；需核合法使用和设计支持范围。

4. 把现成插座/排针换成产品接口时，重新设计信号、电源、ESD、散热、射频与机械固定。

5. 产品PCB大小由器件预布局、镜头/屏/电池/天线净空与结构共同推导；不是等于开发板尺寸，也不是等于42×55mm旧占位。
