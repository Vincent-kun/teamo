## 1. 先确定频段，再确定尺寸

EC800G-CN 国内版与 Air780E 国内版均支持 FDD B1/3/5/8，TDD B34/38/39/40/41；LTE 天线必须覆盖这些目标频段，而不能只看“4G 天线”名称。EC800G 的 Wi-Fi Scan 是接收扫描功能，不能充当完整 Wi-Fi 联网模块。[移远官方规格书](https://developer.quectel.com/wp-content/uploads/2024/09/Quectel_EC800G-CN_LTE_Standard_%E6%A8%A1%E5%9D%97%E4%BA%A7%E5%93%81%E8%A7%84%E6%A0%BC%E4%B9%A6_V1.3.pdf)、[合宙官方 Air780E 资料](https://docs.openluat.com/air780e/product/file/Air780E%E7%A1%AC%E4%BB%B6%E6%89%8B%E5%86%8CV1.0.pdf)。

不能把 Air780E、Air780ER、Air780EEU 等后缀混用。最终 RV1106 主板如果采用合宙 USB 联网，合宙目前说明 Air780ER 是 USB 上网专用推荐方案，Air780E 的 AT 功能表则标记 PPP/USB RNDIS 不支持；这项应先由涛哥确认。[Air780ER 官方说明](https://docs.openluat.com/air780er/)、[Air780E 官方功能表](https://docs.openluat.com/air780e/)。

## 3. 为什么不把天线贴在电池或屏幕后面

厂商证据：FXUB63 说明距金属至少10 mm，理想20 mm；这些数值是该型号的安装建议，不能自动变成所有天线共同标准。FXP14以2 mm ABS安装为测试基准，自带地平面，但这并不等于允许被电池、屏幕金属背板和散热片紧贴覆盖。[FXUB63规格书§1](https://cdn.taoglas.com/datasheets/FXUB63.07.0150C.pdf)、[FXP14厂家说明](https://www.taoglas.com/product/fxp14-2g3g-cellular-flexible-pcb-ipex-mhfi-2/)。

Molex206994应用规范在90×90 mm地平面对照条件下，图6.1平行配置建议至少10 mm，图6.2垂直配置建议至少5 mm，另一个图6.3平行配置写5 mm。**必须结合各图的相对摆位，不能摘出一个5 mm覆盖所有布局。**规范还明确指出安装位置会失谐，装机性能由用户验证；其中示意图是generic，不能标成精确型号实物照片。[Molex应用规范§4、§6](https://www.molex.com/content/dam/molex/molex-dot-com/products/automated/en-us/applicationspecificationspdf/206/206994/2069940100-AS.pdf?inline=)。

本项目排布推断：LTE FPC 沿一侧上段内壁纵向贴装；Wi-Fi FPC放相对侧或顶部独立塑料区域。电池下置、屏幕朝前、PCB居中时，利用上侧空气区留射频净空，避开屏幕金属背板、扬声器磁体与电池。此为方案假设，不能当RF已验证。若无法留出净空，应扩大上部壳体/变更天线位置或采用定制天线，而非仅把FPC实体厚度扣进公差。双天线隔离距离尚未得到同整机量化依据，应留可调贴装位，测S21/共存干扰。

3D打印首版分别测试实际PLA/PETG/树脂材料、壁厚与喷涂后装机；不能直接套ABS基准曲线。外置TG.09用于比较网络表现，最终儿童产品是否允许外露需产品决策。其单极结构依赖主板地；厂家所述>60 mm地平面条件针对700 MHz，不跨频段套用。[TG.09官方说明](https://www.taoglas.com/product/tg-09-2g3g-cellular-connector-mount-monopole-antenna-2/)。

## 4. 给涛哥与供应商的闭环问题

1. 最终联网芯片、LTE精确后缀、Wi-Fi/BLE功能和RF座型号是什么？是U.FL/MHF I还是MHF4？
2. 合作供应商能否提供覆盖国内9个目标LTE频段的贴片天线？精确订货号、原图、尺寸公差、线长、线径、接头/座配对料号、MOQ、样件报价、交期？
3. 各天线在本机PCB、电池、屏背板、喇叭磁体旁所需净空多少？可以按所选打印材料、壁厚和布局审图吗？
4. RF走线保持50Ω并预留匹配网络的位置如何安排？谁负责整机VNA调谐与OTA测试？
5. 能否提供低/中/高频段整机S11、效率、TRP/TIS，以及双天线隔离和LTE/Wi-Fi同时运行结果？同时测试USB充电、屏幕刷新、扬声器大音量、儿童手握/靠墙状态。

以上为拟议验收清单，未声称已经测试通过。采购前优先取ANT01+ANT07样件及供应商同级国产对照，确认合作与成本后再锁型号；开发阶段保留ANT04外置基准，不让开发板天线尺寸决定最终自研主板外形。
