# RV1106 其他开发板排查（2026-10-09）

涛哥仅确认「应该还是使用 1106，已经采购了开发板」。以下是可供拿图片辨认的真实产品，不代表已采购型号或采购概率。只使用厂家一手资料；没有机械证据的尺寸明确保留未知。Luckfox 系列由主调查另行整理。

| 厂家/产品 | 芯片与板型 | 一手尺寸证据 | 对本项目的意义 |
|---|---|---|---|
| 野火 LubanCat-RV06 核心板/整板 | RV1106，核心板加底板；官方有屏幕、摄像头、LVGL、SDK 教程 | 本轮未获得可直接读取的一手机械图，宽高厚未知；第三方转载出现的 35×35mm 不纳入尺寸计算 | 完整底板与核心板不可混算；有显示开发教程，可问是否采购此套 |
| Firefly CT36L / CT36B | 官方明确 RV1106G2；带 SC3336 摄像头的智能相机模组 | 宽高厚未知 | 是相机模组，不能默认当通用带屏开发板；需要确认 RGB/SPI 等接口能否实际引出 |
| ThinkCore TP-RV1106 | 厂家页面明确 G2/G3、核心板+载板、Wi-Fi6/BT5.2、MIPI、音频等 | 厂家页搜索索引可读，但直接抓取存在证书问题；尺寸未知 | 可作为供应商整板路线候选，未能取得可确认原图链接 |
| HINLINK-RV1106 一体化 IPC | 厂家历史 PDF 明确 RV1106 和「38mm 一体化主板」；含镜头/Sensor | 只有「38mm」口径，第二轴及镜头总高未核实；不能直接写 38×38×某厚度 | 摄像头一体板，不等于产品主控载板；需要确认显示输出 |
| HINLINK / Solo-A2 分离式 IPC38 | 厂家官方存在专用介绍 PDF | PDF本次直接读取失败；不把 IPC38 型号名转换为实测三轴尺寸 | 只保留候选名称及附件入口 |
| MuchVision MV13 / 页面参数表 MV14-V1.0 | 页面明确 RV1106G2/G3 可选、视觉相机板 | 厂家表列 Device Size **38×38×20mm（可定制）**，但页面标题 MV13、参数表 MV14 不一致 | 尺寸暂列供应商页面声明，禁止与裸板厚度混用；型号冲突需供应商解释 |
