紧凑软包路线优先询价 2000–2500mAh、带PCM与NTC、连续电流按整机峰值预算定制的成品包；现有参考型号尚未证明全负载满足。薄型1100mAh包可做低功耗对照，不直接推荐为整机主电池。

圆柱路线优先对照单节18650成品包与1S2P成品包：厚度约18mm起，换取刚性电芯与容量，但保护板、线材、支架仍占空间。裸P28A是电芯能力参考，不能直接接入开发板。

若未确认断电使用场景，第一版台架可外接USB供电；电池供电、边充边用、充电温控与4G瞬态作为独立验证项。
