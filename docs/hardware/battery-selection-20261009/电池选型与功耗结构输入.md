# 电池选型与功耗结构输入｜2026-10-09

本轮为真实型号候选研究，不冻结采购。产品自研PCB，开发板不作为产品板尺寸。

## 决策输入

默认讨论工况为负载平均5W、转换效率85%、可用能量比例80%、电池低压端3.3V。全部是预算，实际需测RV1106、相机、背光、4G、功放同时工作的功耗。

电池端平均电流约5/(0.85×3.3)=1.78A；峰值另算，不能用平均值选保护板。2000mAh/3.7V估算可供负载7.4×0.85×0.8=5.03Wh，即约1.01h；1100mAh约0.55h。可用比例需依据截止电压、老化、温度和电芯曲线修正。

LiPol 1100mAh明确连续1.1A；默认工况不满足平均需求。EEMB HA裸芯最大电流不代表成品包连续电流。P28A的电芯35A也不能转化为保护板、线材与连接器35A。

## 结构

软包路线先比较2000–2500mAh成品包，但需含PCM/NTC最大尺寸和连续能力。圆柱路线比较单节与1S2P成品包，长度按保护包而非裸芯算。软包需绝缘、无尖边、保持不受螺柱及PCB挤压；膨胀余量由供应商指定，不擅自指定万能间隙。

打印预留分为电池最大公差、装配间隙、支架、线材/插头和供应商膨胀预留；可视排布的暂定值不代表3D干涉验证通过。

## 供电候选与缺项

- [BQ24074](https://www.ti.com/product/BQ24074)：单节线性充电、PowerPath与温度输入候选；1.5A充电上限不是整机负载能力。边充边用热耗散及系统电流需设计计算。
- [TPS61088](https://www.ti.com/product/TPS61088)：升压候选；10A是开关相关规格，不是5V输出10A。自研板须按电感、低压效率、PCB和热条件核输出。
- [MAX98357A](https://www.analog.com/en/products/max98357a.html)：I²S功放候选；RV1106引出及SDK、供电和喇叭阻抗要匹配，最大标称功率不是喇叭长期输入要求。
- [EC800G-CN厂家参考设计](https://images.quectel.com/python/2023/05/Quectel_EC800G-CN_Reference_Design_V1.1.pdf)：4G供电独立退耦与瞬态验证；按具体订货版本硬件指南定电压和峰值。

充电、保护、PowerPath、升降压、电量计是不同功能，不能拿一块“充电板”替代全部。无线模块若最低工作电压高于电芯截止电压，需要单独的电源轨策略。
