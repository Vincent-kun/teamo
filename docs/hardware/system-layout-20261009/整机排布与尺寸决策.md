# 整机排布与尺寸决策｜2026-10-09

工程讨论版，非CAD或BOM冻结。尺寸为圆角长方壳W×H×D，不是球体或直径×高。

| 方案 | 外包络mm | 前脸下限mm | 深度栈mm | 外接盒体积cm³ |
|---|---|---|---|---|
| 紧凑方屏 / Wi-Fi优先 | 63.2×102.3×39.1 | 101.13 | 35.50 | 252.8 |
| 圆屏 / LTE优先空间 | 76.4×123.6×47.2 | 123.00 | 39.00 | 445.7 |
| 裸圆屏 / 圆柱容量路线 | 73.2×118.4×45.2 | 117.59 | 38.96 | 391.7 |

黄金比例是造型目标：H≈φW、D≈W/φ，0.1mm为讨论精度，不是制造能力。体积是外接盒或R15圆角平面等截面估计，不是内部可用体积；真实胶囊/曲面CAD会变化。

S1：1.69触控屏＋CMS-30204-18L250，主板与2000mAh软包前后层叠；Wi-Fi优先。S2：55×55圆屏＋CMS-28528N-L152，侧壁FXP14；推荐作为LTE空间起点，QSPI/协处理仍是条件。S3：裸圆屏＋1S2P4400mAh包，容量与厚度对照，射频区域不足时增大至S2宽度。

相机参考MIS5001B25×24，24mm安装深度暂定；它不是120–130°FOV已确认件。自研PCB42×55×10为工程占位，主控/RAM/eMMC、4G、电源、音频、SIM及连接器全部需布局后验证，不能用模组面积相加证明可布完。

打印初值壁厚2mm、螺柱位置待CAD；工艺、材料、方向、翘曲及收缩未知，先打槽/螺柱/卡扣试片再用卡尺测误差。0.3mm装配补偿可作为试片A/B参数，不能当所有工艺通用公差。电池公差采用厂商最大包络，膨胀预留供应商指定。屏框、相机镜头、连接器线缆须各自计误差链。

后腔35×30×10mm净空另计腔壁、垫片、5.2mm喇叭厚度与1.5mm前侧试验间隙；前后声路隔离。主板与电池不侵占净空。

LTE布置试验：42PCB＋20天线区＋10隔离＋4壁=76mm；10隔离未得到FXP14厂家保证，RF供应商审图后修改。Wi-Fi需按具体安装配置应用规范的5/10mm等距离审图，不统一写万能5mm。塑料/屏蔽罩/电池/磁铁/螺丝影响调谐。

完整系统尚待选：USB-C座（CN01–03）、SIM座（CN05–07）、电池/喇叭接头（CN15–19）、FPC座/线长（CN04/CN29–30）、按键（CN17–18）、麦克风/声孔、NTC/PCM、电量计（PWR14–16）、热路径、屏窗口与密封材料。连接器候选已带真实型号，见全品类补全总览。

成本：公开美元价是样件参考，供应商合作、MOQ、芯片/PCB/SMT/NRE、结构打印、声腔、RF调试、物流税费皆未闭环，不能承诺≤2000元。确认是否有现成硬件方案比只选便宜芯片更关键。

验证顺序：板型/SDK和网络方式 → 电源平均/峰值 → 屏点亮/触控 → 摄像头/FOV和算法 → 声腔/AEC → RF审图/样机 → CAD干涉 → 打印试片/整机 → 续航与热测试。

这三个方案是在比较：**做小一些、给圆屏和4G留更多空间，还是给电池留更多空间。** 它们都是尺寸讨论草案，尚未证明所有零件能顺利装进去。

尺寸顺序为 **宽×高×厚**。

| 方案 | 预计大小 | 核心取舍 |
|---|---|---|
| S1 方屏＋Wi-Fi | 约 **6.3×10.2×3.9厘米** | 优先紧凑 |
| S2 圆屏＋4G空间 | 约 **7.6×12.4×4.7厘米** | 用较大机身容纳圆屏、声音和天线 |
| S3 薄圆屏＋大电池 | 约 **7.3×11.8×4.5厘米** | 把屏幕省下的厚度让给电池 |

**S1：先做一个较小、方便验证的版本。**

正面从上到下放摄像头、方屏、薄型椭圆喇叭。内部像叠三明治：**屏幕在前，主板在中间，电池在后面**。电池按约2000mAh软包作尺寸参考。

它小，是因为屏幕和喇叭占的正面面积较少。代价是内部空间紧，4G天线还没有找到可靠的安装位置。因此这套先按家庭Wi-Fi使用讨论。

适合拿来验证"运动识别、屏幕反馈、语音播报"这条主链路；声音是否够用、电池能否稳定带动整机，都要测。

**S2：为圆屏外观和内置4G，接受更大的机身。**

圆形画面背后的整块屏幕组件，暂按 **55×55mm** 算；下面换成较大的圆喇叭，并给它留独立的后腔——可以理解为帮助喇叭发声的小空箱。

主板和电池偏向一侧，另一侧给4G天线留位置。天线周围还需要一些远离金属的空间，所以不是"薄薄一片，贴哪里都行"。

这套更适合作为**圆屏＋内置4G**的讨论起点。但圆屏如何驱动、天线位置是否有效，还没有验证；机身变大也不等于声音或信号已经合格。

**S3：用更薄的圆屏，换取更大容量电池。**

这里选的是不带额外控制载板的薄圆屏，参考厚度约 **1.96mm**。省下的空间用于放约4400mAh的双圆柱电池包，它本身约 **18mm厚**。

它的思路是：**屏幕做薄，电池做大**。代价是自研主板要承担更多屏幕接线和驱动工作，电池也更厚、更重。容量更大有利于续航，但具体能用多久仍取决于实测功耗。

另外，这套当前宽度还不足以沿用S2那套4G天线隔离预算。如果坚持内置4G，可能还要加宽或重新排布。

找涛哥讨论时，可以这样说：

> 我准备了三条路线：S1先做紧凑的Wi-Fi版本；S2给圆屏和内置4G留空间；S3用薄圆屏换大电池。想先确认哪条主板、屏幕驱动和供应链最成熟，再收敛机身尺寸。

当前尺寸是把硬件空间预算和黄金比例结合后得到的。**黄金比例负责外观协调，最终大小还得由真实板子、线材、声腔、天线和打印装配决定。**
