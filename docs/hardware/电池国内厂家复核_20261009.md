## 初筛解释与对接问题

1. 三款 EEMB 属于有真实型号和尺寸依据的电芯候选，仍需厂家完成 PCM、NTC、连接器、线材成品配置；不能拿裸电芯尺寸宣布已能装入产品。
2. LiPol 这款有完整保护包配置与明确连续电流，便于核对充电方案；若后续实测整机电池端持续电流超过 1.1 A，它就不满足该条件，不能用 2–4.5 A 过流阈值挽救筛选结果。
3. EEMB 高倍率型号值得向涛哥和供应商核实，但“10C”并不保证成本适合、团队已有合作、成品 PCM 也承受同等电流。报价、MOQ、样品交期、现有合作全部未知。
4. 要求供应商提供成品最大包络（含 PCM/NTC/胶带/折边及公差）、膨胀预留、极耳方向、线长和插头极性；提供连续放电温升曲线、瞬态电流时长、PCM 型号/动作阈值/恢复条件，并出对应成品配置正式承认书。
5. 向涛哥确认 RV1106 自研板、屏幕背光、摄像头、音频及 4G 同时运行时的电池端平均/峰值电流和最低电压。整机续航据实测输入功率计算，目前不能凭 mAh 给出保证时长。

本轮仅增加研究记录，没有更改 PRD、BOM 基线或采购状态。
