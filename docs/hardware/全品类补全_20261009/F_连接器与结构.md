## 二、3D 打印试片计划（结构验证用，随首批机身同板打印）

1. **孔径补偿试片（热熔螺母 CN22/CN23）**
   - 底孔三档：Φ3.2 / Φ3.3 / Φ3.4（螺母外径 Φ3.5）
   - 每档 ×2 材质（PLA / PETG）×2 螺母纹型（直纹/双斜纹）= 12 孔
   - 热熔工艺：恒温烙铁 210℃ / 230℃ 两档
   - 验收：锁 M2×6 螺钉反复 10 次不滑牙；拉拔力 ≥50N（弹簧秤粗测）
2. **自攻底孔试片（CN24）**
   - 底孔三档：Φ1.6 / Φ1.65 / Φ1.7，M2×6 直接自攻
   - 验收：不裂不白、退出再进 3 次保持力可接受
3. **按键孔配合试片（CN17/CN18）**
   - 帽孔间隙三档：0.10 / 0.15 / 0.20mm（直径向）
   - 侧键臂过盈两档：0.2 / 0.3mm
   - 验收：手感不发涩、回弹正常、无卡死
4. **卡扣间隙试片**
   - 悬臂卡扣配合间隙：0.05 / 0.10 / 0.15mm，悬臂根部圆角 R0.3/R0.5 两档
   - 验收：装拆 20 次不永久变形
5. **USB-C/SIM 插入口试片**
   - 开口单边放大：0.1 / 0.2 / 0.3mm（对照连接器公差 + 打印收缩）
6. **壁厚与热熔区强度**
   - 螺母区局部壁厚 2.0 / 2.5 / 3.0mm 三档，观察热熔时是否烫穿/溢料

## 三、装配空间提醒（排布未闭环项清单）

1. **USB-C 插拔区**：开口深 ≥8mm + 线缆弯折半径 ≥5mm；插口不要贴壳内壁，留 0.5mm 对位余量。
2. **SIM 取卡方向**：自弹式需正面 15mm 操作空间；卡托式需侧面槽+退托行程——必须先定取卡手势再定 4G 模组位置。
3. **电池/喇叭插头插拔**：所有卧贴座子插拔方向前出留 ≥10mm 无遮挡；禁止插拔方向朝壳壁。
4. **CSI/FPC 弯折**：FFC 弯折半径 ≥5mm，禁止锐角 U 弯；接头掀盖式要 Z 向 2.5mm 掀盖空间，抽屉式要 5mm 抽拉行程。
5. **麦克风声孔**：硅胶圈密封，孔径 Φ1–1.5mm，背面留前腔空腔，远离喇叭出声孔防自激。
6. **按键**：帽高出壳 ≥0.3mm，间隙按试片定；侧键传力臂需刚度加强筋。
7. **螺柱/热熔螺母**：Φ3.5 螺母中心距壳边 ≥3mm，底孔区背面避免打印悬空；M2 螺母点位建议 4 角 + 屏/喇叭压点。
8. **绝缘**：电池整片麦拉（0.1mm）+ 喇叭磁体对板背面麦拉；喇叭后腔 EVA 密封一圈。
9. **散热**：RV1106 顶面到壳内壁间隙实测后定导热垫厚度（0.3 或 0.5mm）；壳内壁对应区域可加粗糙纹理增散热。
10. **密封**：本机按生活防尘设计，前后壳拼缝可加 0.8mm EVA 压条，不追求 IP 等级。

## 四、给涛哥的问题（采购/供应商）

1. **现有供应商**：连接器这批（USB-C / SIM / FPC 座 / PH-XH）是否已有合作代理或嘉立创直购习惯？CN02、CN12、C11055 都是嘉立创现货爆款，可直接 BOM 配单。
2. **可拿样**：热熔螺母（新宏辉达 CN22/CN23，50 个起订 ¥0.07/颗）、导热垫（NDST）、麦拉/EVA 模切厂——能否安排免费样/小批量试片料？
3. **电池引线规格**：1S 软包带 PCM 引线目前是啥端子/线径（AWG）？决定 CN12 vs CN14，请电池厂出引线压接端子规格书。
4. **喇叭引出形式**：喇叭厂交付是引线还是弹片？若弹片可焊线直连省连接器；若引线默认端子型号？
5. **Molex 链路**：CN13 三件套（胶壳+端子+板端）是否走 Molex 代理拿样？小批量总价比 CJT 贵多少？
6. **FFC 排线**：A/B 型与长度要等排布定稿，是否可先按 100mm A 型 20P 备 5 条验证？
7. **打印工艺**：首版机身用什么材料/打印机（PLA/PETG/PA12-CF）？决定热熔还是超声埋入与底孔三档取舍。
