## 3. 已发现的参数冲突（待规格书页码核实）

1. SGM41513 充电电压精度：官网中文页 ±0.6% vs 英文摘录 ±0.5%。
2. DW01A 过充释放电压：4.15V vs 4.10V 两个流通来源。
3. SGM2212 输出电流：官网 800mA vs 流通资料 150mA（封装表述也不同）。
4. LC709203F 静态电流：官网特性页 3µA vs 应用手册 15µA。
5. MT3608 输出 2A（商城）与开关限流 4A（LCSC 引文）关系。
6. ME6211 静态电流/精度在不同版本文档间 30/40/50µA、±1%/±2% 差异。

## 4. 给涛哥的问题（阻塞电源架构收敛）

1. **整机功耗实测**：RV1106 典型平均功耗与 4G 发射 1.5~2A 脉冲@3.8V 的持续时间/占空比待测——决定走 PWR01 线性路线还是 PWR05/PWR04 NVDC 开关路线。
2. **充电热**：若用 TP4056 1A 线性充电，封闭外壳内约 1.5W 热耗的结温与外壳温升可接受吗（儿童接触面限温）？不可接受则开关型充电成为必选。
3. **断电续航语义**：USB 拔出瞬间是否要求系统不重启（UPS 语义）？是→PowerPath 必选（PWR01 或 NVDC）；否→PWR03 极简路线可行。
4. **充电电流上限**：按 0.5C，850mAh 电池约 425mA、2500mAh 约 1250mA；是否要求 2 小时充满？决定 PROG/IINDPM 设定与适配器要求。
5. **电池是否带 PCM+NTC**（电池工作包结论）：决定 PWR06/PWR07 是否上板与 NTC 复用路线。
6. **低电关机与运输模式**：是否需要 BATFET 运输模式（PWR04/PWR05 支持）拉长库存/运输期电量保持？
7. **RV1106 各电源轨划分**：核心轨电压/电流、DDR 轨、外设 3.3V/1.8V 需求清单——PWR08~PWR11 的取舍依赖此输入。
