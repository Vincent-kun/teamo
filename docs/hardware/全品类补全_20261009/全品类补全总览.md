## 3. 关键技术结论

1. **RV1106 内置 codec 可省外置 Codec**：2×24bit ADC（90dB SNR）+ DAC + 可编程 MICBIAS + ALC/AGC，I2S0_TDM 8ch → 「模拟 MEMS 麦 + 模拟功放 NS4150」是最省料路线；TLV320AIC3104 降为可选。
2. **AEC 在主控软件层**（Cortex-A7，RKMedia 对讲 AEC + RKAPPLUS 库，编译开关未显式开启待核）；回采参考由 codec 数字回采（Mode2）提供。
3. **Wi-Fi 官方支持路线唯一明确的是 AIC8800DC**（Luckfox Pico Ultra W 板载，Wi-Fi6+BT5.2）；RTL8189FTV/AP6256 驱动待核；ESP32-C6 是唯一可作 SDIO 从机的协处理器选项（esp-hosted Linux 支持待核）。
4. **广角摄像头是全链路最大技术缺口**：现有可驱动传感器最高 DFOV 84°（OV5695），距 120–130° 目标差 36–46°；GC2093/SC3336 等 ≈70–78°。现有 MIS5001B（95.5°）是最广的已验证件。
5. **连接器不是"随便买"**：Molex 104031-0010 实为 microSD 座（网传 Nano SIM 有误）、MUP-C792 是 Micro SIM；1.25mm 电池座额定 1A，4G 峰值脉冲须用 PH2.0（2A）或降额论证。

## 4. 给涛哥/魏子奇的问题清单（按优先级，汇总自各包）

1. **摄像头**：120–130° 的 H/V/D 口径与畸变容忍度是多少？算法侧真实需求？是否接受定制广角模组（MOQ/NRE vs 2026-11-15 死线）？广角 IQ 调优资源谁出？
2. **主控**：已购开发板具体是哪块？RV1106 芯片后缀（RV1106/RV1106B/RV1103）？SDK 版本？路线 B（核心板+载板）是否可复用现有设计？
3. **AEC/语音**：RKAPPLUS AEC 默认开关与 CPU 余量？语音使用距离/音量要求（决定功放功率与麦克风灵敏度）？NS4168 在 8Ω 下功率取舍？
4. **网络**：是否必须内置 4G + 断电工作？USB 联网用 EC800G 具体固件还是 Air780ER？Air780E RNDIS 规格书与 AT 表口径冲突需与合宙确认？
5. **功耗与供电**：整机平均/峰值功耗实测值或估算？充电电流上限（热约束）？是否有现成电源方案/合作供应商？
6. **供应**：电池/喇叭/天线/摄像头模组有无国内合作供应商与报价？哪些型号本周可拿样？
7. **结构**：3D 打印供应商与工艺（FDM/树脂）？试片计划排期（见 F MD §试片）？

## 5. 未闭环项登记（不隐藏）

- 蜂窝模组官方峰值电流均未公布（仅生态口径 1.5–2A 参考）；无人民币报价。
- RTL8189FTV/RTL8188EU/esp-hosted 在 RV1106 Linux 5.0 的驱动未核。
- 摄像头 4 条缺厂家图（vanxoak 超时/frbiz 503/oe1 超时/gcoreinc JS渲染）；C07/C09/C11 模组厚度 null。
- 4 份电源规格书直链未获取（DW01A/MP2315/MT3608/CW2015），已记下一核实路径；MP2315 与 NCP15 为 NRND 需替代。
- IM69D130 官网标 not for new design（已保留为对照）；MSM261 输出类型（I2S/PDM）渠道冲突待 FAE 终核。
