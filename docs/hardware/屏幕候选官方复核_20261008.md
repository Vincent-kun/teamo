## 2. 必须保留的冲突和边界

- D03 同页正文写 15pin，规格表和引脚表写 10pin；供电表写 2.8V，引脚表写 LEDA/VCC 3.3V。需厂商提供指定版本 datasheet、引脚图、背光电路与完整 FPC 图，才能交付 PCB。网页中的“可定制 MIPI/RGB”等营销文字不代表此 SKU 已具备该接口。[厂家页](https://www.nosedisplay.com/products/tft-display-1-8-inch-round-display-ips-360x360-resolution-qspi-4-line/)
- D04 是独立屏模组；D05 是已搭载 ESP32-S3 的开发板，两者虽均 55 × 55，也不能复用厚度、供电或驱动结论。D05 板载电池充放电功能不证明能同时为外部 RV1106 和 4G 供电。[D04](https://docs.waveshare.com/1.85inch_Touch_LCD_Module)、[D05](https://docs.waveshare.com/ESP32-S3-Touch-LCD-1.85)
- 官方 RV1106 RGB 教程只支持列明的 Ultra / Ultra W 与 LF40 型号；教程要求其他分辨率另行适配。不能外推 Core 或 BodyPark 同芯片主板已支持所有小屏。[官方教程](https://wiki.luckfox.com/Luckfox-Pico-Ultra/RGB-Screen/)
- D01 商品检索结果含美元展示价，但抓取缓存较旧；本附录不将其作为当前国内采购价。六个候选都应取得对应型号、版本、含税人民币、库存与交期报价。

## 3. 给整机尺寸讨论的屏幕输入

现阶段同时保留三条尺寸路线：D01/D02 小方屏、D03 紧凑裸圆屏、D04/D05 55mm 圆屏模组。D06 只承担台架软件验证。屏幕只决定若干尺寸下限，最终机身还受载板、电池、镜头、声腔、线束、散热与天线影响。

按现行临时打印预算，单轴加项为双侧壁 4.0 + 双侧装配间隙 1.0 + 部件正偏差 0.2 + 内腔缩小预算 0.3 = 5.5。这是方案假设，不能当打印厂精度承诺。宽度筛查需采用装配姿态下横向尺寸，并验证圆角处净空：

| 屏方案 | 屏单件横向基准 | 临时外宽下限，仅宽度筛查 |
|---|---:|---:|
| D01 竖屏 | 31.50 | 37.00 |
| D02 竖屏 | 33.13 | 38.63；已知 ±0.05 若替代通用部件正偏差，应重算且避免重复累计 |
| D03 长边沿机身高 | 48.08 | 53.58；屏转 90° 则 55.09 |
| D04 或 D05 | 55.00 | 60.50 |
| D06 台架屏 | 84.20 | 89.70 |

该表不是建议把机身做成这些宽度。Core 30mm 核心板还需载板；Ultra 50mm 开发板还需接插件净空；电池包络含保护板和引线。应先做完整堆叠，再定外宽、外深、外高，黄金比例作为形态目标与硬件约束共同讨论。

## 4. 带给技术负责人的决策材料

1. 先选显示架构：RV1106 直接 SPI/QSPI 驱动，还是 RV1106 发事件给 ESP32 渲染。要求负责人指出具体 SDK、参考代码、引脚资源、预期帧率与开发工时。
2. 用 D01/D02 与 D03/D05 两种形态分别做正面、侧面包络；未知厚度标记临时占位，记录取值和余量。
3. 带厂商图纸、报价和样品交期讨论；若圆屏接口适配无法承诺，应保留方屏验证或双处理器路线，而不冻结 ID 后再等待驱动。
4. 样品到货后检查点亮、角色动画、计数文字、观看距离可读性、功耗和温升。通过后才冻结最终屏 SKU、载板连接及机身。
