# 硬件全品类选型与整机排布执行规范 V1.0

日期：2026-10-09。需求负责人：魏子奇。技术对接：涛哥，具体姓名与职责待确认。

适用任务：扩充真实硬件候选、核对厂家图片和尺寸、比较技术路线、推导首版3D打印机身，并形成可供硬件负责人讨论的方案。

本规范约束后续研究与交付方式；不是已冻结产品规格、采购授权或可制造图纸。它与项目根目录 AGENTS.md 一起使用，资料权威顺序仍按 AGENTS.md。

## 1. 目标与执行边界

项目是儿童AI运动陪伴机器人，主链路为视觉采集、运动识别、计数/评分和角色化反馈。MVP截止日期是2026-11-15。研发中涉及的视频处理遵守现行产品边界。

必须落实的用户要求：

- 全品类比较真实可查型号，而非只展示两三个已知样件。
- 成本、现有供应商、成熟方案、团队SDK/驱动经验共同参与判断。
- 主控暂沿RV1106系列研究，准确芯片后缀与已购开发板待涛哥确认。开发板用于验证，产品需要自研PCB。
- 同时保留圆屏和方屏路线；接口筛选产生的结果不能变成未经产品决策的外观结论。
- 60×90mm只是竞品启发的初始尺寸，不是硬约束。先满足硬件，再比较比例。
- 造型考虑黄金比例，尺寸来源与推导过程可追溯。非整数表达需要工程依据，不能为了显得精确随意添加小数。
- 第一版工艺为3D打印，要计入公差、装配、线缆、热、射频和声学空间。
- 交付真实型号图片、结构排布及决策理由，并把问题整理好交给涛哥讨论。

本轮默认授权范围为研究、候选数据、文档与本地可视化制作。联系供应商、发消息、下单、改采购状态或冻结BOM须来自用户对应授权。既有PRD、甘特图与历史资料按仓库规则保留。

## 3. 全品类覆盖标准

下列数量是研究覆盖目标，不是最终采购数量或市场穷尽声明。保留不同技术路线的对照项，重复型号、颜色或同板不同镜头不得伪装成独立架构。

| 类别 | 候选覆盖目标 | 必须比较的维度 |
|---|---:|---|
| 主控与自研板方案 | 3条架构路线 | RV1106芯片自研、核心板+自研载板、成熟供应商方案；开发板另列 |
| 显示屏 | 圆屏、方屏各≥5条代表记录 | SPI/QSPI/RGB及必要的协处理路线；裸LCM/触控/载板分别识别 |
| 摄像头 | ≥8条代表记录、≥3个传感器族或供应方案 | SDK成熟CSI、宽角镜头、USB对照；像素/FOV/畸变/帧率/ISP |
| 蜂窝联网 | ≥6条代表型号/方案 | 国内Cat.1频段、USB或UART网络方式、AT/固件、Linux驱动和电源峰值 |
| Wi-Fi/BLE | ≥3条不同实现路线 | 主控既有无线、Linux无线模组、协处理器；BLE需求单独确认 |
| 电池 | ≥10条、含至少3条国内厂家候选 | 软包/圆柱、裸芯/带PCM+NTC成品包、容量与电流、完整包络 |
| 喇叭 | ≥8条 | 单体/自带腔体、圆/椭圆、阻抗、额定功率、声压测试条件与安装 |
| 功放 | ≥3条 | 模拟/I²S、驱动与供电、负载和限幅；独立于喇叭 |
| 麦克风与音频采集 | ≥3条路线 | 模拟MEMS/I²S/PDM或Codec方案、接口资源、驱动、AEC和声孔 |
| 天线 | LTE≥4条、Wi-Fi/BLE≥3条 | 精确频段、FPC/PCB/外置、接头线长、净空、地平面和材料 |
| 电源及电量管理 | 每种功能≥2条路线或解释复用理由 | 充电、PowerPath、保护、稳压/升压、电量计、温度检测 |
| 连接器及结构辅料 | 每种实际功能≥2条可查候选 | USB-C、SIM、CSI/屏FPC、电池/喇叭接头、开关、螺柱、绝缘与密封 |

若真实供应、SDK支持或尺寸证据不足以达到目标，交付已查池和检索日志，说明检索范围、排除原因、还缺哪些供应商输入。用品牌或市场平台名称代替型号不计入达标。

## 4. 单个候选的数据与证据规范

### 4.1 最低字段

所有JSON/CSV记录应能映射到以下字段。可保留现有数据结构，在合并时完成显式字段映射。

| 字段 | 要求 |
|---|---|
| `id / category / manufacturer / model / revision` | 稳定ID、独立类别、完整订货号与版本；未知版本写null |
| `assembly_level` | 芯片、裸电芯、裸LCM、模组、带载板组件、开发板、整套方案之一 |
| `dimensions` | 明确轴定义、单位、主体与装配包络、最大值/标称值、公差、线材/接头边界 |
| `electrical / interfaces` | 各类必需电气字段；额定/最大/峰值/保护动作值分别标注 |
| `host_support` | 指定主控/板型/SDK版本、厂家例程或驱动来源、团队熟悉度状态 |
| `sources` | 每组关键事实对应厂家页/规格书URL、页码/图号、版本、核查日期 |
| `images` | 原始URL、来源页、下载路径、图类型、精确版本对应关系、SHA256 |
| `commercial` | 币种、数量阶梯、税运费、报价日期、MOQ、交期、供应商关系和报价证据 |
| `decision / reasons / missing` | 推荐询样、条件保留、对照或淘汰，以及具体原因与缺项 |

未知数值使用null，不用0或凭照片估值。完整T未知时，结构图可设置独立的`assumed_envelope`，必须带假设理由、负责人待确认项，不能覆盖厂商数据。

### 4.2 来源与冲突

- 技术事实以厂家原始规格书、型号页、官方SDK/源代码为主。经销商可补报价和供货，但不能悄悄覆盖厂家参数。
- 商品页、图纸和不同版规格书冲突时，并列旧口径、新证据及需要确认的参数；结构预算可用有说明的保守边界，仍保留“冲突未闭环”。
- 芯片支持某接口不等于已购开发板引出该接口，也不等于现有SDK有驱动。分别核芯片、板型、软件和团队验证。
- 裸芯/模组尺寸只表示该层级器件；保护板、连接器、线材、天线、腔体及载板另计。
- 国内合作供应商和团队经验目前未知，按问题记录。公开零售库存不能证明国内供货，美元样件价不能直接算成含税量产BOM。

### 4.3 真实产品图片

先观察原始页面，再保存对应型号资源，下载后查看图片内容。

标记至少区分：精确型号产品图、型号族参考图、版本待核图、机械图、渲染/示意图、竞品实机图、缺图。机械图与示意图不能标为实物照片；厂家展示画面不是团队点亮验证。

有图条目支持查看大图、原始来源与图类型。尺寸从图纸或厂家参数取得，照片不用于比例测量。找不到精确型号图时显式记录缺图原因；不用近似型号填满图片区。

## 5. 分类别筛选规则

### 显示屏

先分普通SPI、QSPI、RGB等接口，核完整模组/触控玻璃/FPC/背板包络，再筛对角线、像素、亮度与触控。圆形显示区域不代表模组外形是圆的。

圆屏池和方屏池分别展示默认条件与淘汰理由。普通SPI筛出方屏时，只说明该条件的结果。QSPI路线保留“主机实现/驱动待核”，不自动判定已支持或永久不可用。CSI摄像头接口不能当作显示DSI。

### 摄像头

分别核传感器与具体镜头。记录H/V/D FOV、畸变定义、固定/自动对焦、照度、帧率/格式、接口/引脚、电压、完整镜头深度、ISP/SDK版本。角度不足的成熟验证件可作台架对照，不升级为符合广角目标的产品相机。

相同传感器的A/B镜头计作配置记录，单独统计传感器族/实现路线数。USB摄像头须核主机资源、UVC、带宽和功耗，不能作为CSI模组的无代价替换。

### 网络与天线

区分蜂窝模组、Wi-Fi/BLE模组、协处理器与整板；型号区域后缀和固件锁定后核频段、USB/RNDIS/ECM/PPP等网络方式。UART AT通信存在不代表支持目标联网方式。

天线逐项核目标模块所需全部频段、阻抗、接头类型及配对座、线长、地平面、金属净空和塑料测试条件。LTE与Wi-Fi区域及馈线作为独立空间占位。净空以具体型号/安装配置资料为准；未取得时用可追溯试验假设，并标明审图及装机调谐待完成。

### 电池和供电

容量、标称电压、最低容量、连续放电、峰值时长、最大充电、PCM阈值/恢复条件和NTC分别记录。裸电芯最大电流、线材额定、过流保护阈值不能代替成品包连续能力。

能量预算：`t≈C_Ah×V_nom×η×k÷P_avg`；电池端平均电流：`I≈P_avg÷(η×V_low)`。η、k、P均说明来源；未知时给多工况敏感性分析。另算峰值、截止电压、温度和老化，估算续航标“非实测”。

充电、保护、PowerPath、升降压、电量计、温控功能逐项覆盖；电源芯片开关电流不作输出电流。USB外接验证与整机电池路线分别列出。

### 喇叭、功放及麦克风

喇叭按额定功率而非营销最大功率筛选；跨型号SPL只在测试距离/功率/频段一致时比较。功放与采集独立分类，核主控引脚、SDK、负载、增益/限幅和AEC。

单体喇叭后腔、前侧振膜间隙、格栅、密封和线材作为独立结构组件。自带腔体按完整组件图纸计。试验腔容积必须标工程假设，后腔净空气体积不能被电池/板/线束占用。麦克风位置、声孔和出音路径要进入排布图。

## 6. 组合、排布与尺寸推导

至少交付三套组合：紧凑/快速验证、圆屏/产品形态、容量或声音优先。每套必须包含：主控板实现、屏、相机、联网、LTE/Wi-Fi天线、电池、供电、功放、喇叭/后腔、麦克风、必要接头和结构空间。

每套输出以下内容：

1. 精确型号组合表，真实部件与工程占位分列，列接口、电源、驱动和机械冲突。
2. 正/侧/背投影或三维包络图，用统一mm坐标、明确层次和标尺。显示区域形状、模组板框分别绘制；射频区、声腔、热区和插拔区可辨识。
3. W左右、H上下、D前后下限公式，标明同平面相加与前后层叠，包含连接器、排线弯折、安装边、壁厚与误差链。
4. 黄金比例比较：先算硬件下限，再选造型比例与工程取整，说明H/W或W/D是否采用φ。不要默认三轴必须同时满足φ；给出强制比例的体积代价并供用户选择。
5. 外接盒体积、假设曲面体积与CAD内部可用体积分开；宽×高×深不是内部容量。圆角、胶囊曲面与壳体有效截面纳入图纸检查。
6. 续航/平均与峰值电流、初步热路径、RF/声学条件、费用缺项与方案推荐理由。

黄金比例和0.1mm表达属于设计讨论精度，不等于3D打印制造精度。支架、螺柱、屏蔽、磁铁和线束要进入包络清单。PCB外形须结合布件、层数、地、天线、电源、走线和连接器验证，不能用芯片面积求和宣称“装得下”。

### 首版3D打印

先明确工艺、材料、方向、喷嘴/层高或树脂精度。记录供应商能力或试片实测，再定壁厚、孔/槽补偿、卡扣、螺柱和热熔螺母尺寸。

电池厂家最大包络、公差、线材与膨胀预留分别计入；打印补偿是另一项。关键配合用试片A/B验证。把零件实体干涉、装配操作、振膜行程、线材弯折和RF/热/声学禁占区分别检查。

完成尺寸推导后仍标“讨论方案”；只有具备可信的CAD包络与对应检查记录，才可写机械验证通过。

## 7. 方案决策与对接涛哥

推荐不以型号数量或单价排名。按以下顺序解释：功能满足 → 接口/SDK可实现 → 结构与供电 → 现有供应和成熟方案 → 成本/MOQ/交期 → 风险和验证工时。

每套交付一条决策链：选择的型号、淘汰的近似方案、支持证据、工程代价、剩余缺项，以及哪个答案会改变推荐。

必须整理给涛哥的问题：已购板型/芯片后缀/SDK；可复用自研板与供应商；屏幕路线与驱动经验；目标FOV和算法需求；联网方式和具体固件；是否必须内置4G/断电工作；续航、声音使用距离；平均/峰值功耗；已有电池/喇叭/天线供应；MOQ、报价和可拿样日期。未知信息不得由Agent自行“确认”。

成本表将物料、PCB/SMT、NRE/软件适配、结构打印、射频/声学调试与物流税费分开。≤2000元是目标，不是缺项情况下的已达成结论。

## 8. 交付与验收

交付：研究MD、可复用JSON/CSV、图片及来源清单、候选工作台、完整组合BOM草稿、排布/尺寸决策、涛哥问题清单、检查记录与交接。

页面沿用企业物料工作台风格：灰白底、克制蓝色、统一导航/搜索/筛选/导出，数据清单与产品图片切换。显示数量与类别统计自动来自数据；未知值、版本和来源可查看。界面质量不能替代研究覆盖。

验收逐项核对：

- 各品类达到覆盖目标或交出可核查缺口记录；变体数量与独立路线数明确。
- 每条身份、主要技术参数、尺寸、电气与商业状态有来源；已选择组合没有未说明的关键未知。
- 图片与型号对应，资源可打开；图纸、参考图、缺图不冒充实物图。
- 每条候选都有筛选理由，所有方案包含未闭环风险。
- 图中所有实体、假设和禁占空间可追溯；前脸、深度、天线及声腔预算互不矛盾。
- 重建页面不丢新增候选或图片来源；原始数据、编译脚本和输出一致。
- 检查搜索、筛选、类别数量、单位、公差/未知、图片、导出和链接；检查1440/768/390/320宽度。机械/电气/RF验证与页面验证单列。
- 工具或网络阻塞时保留完成成果，记录失败步骤和影响。未执行检查写“未执行”，不要沿用旧版报告宣称新版本通过。
