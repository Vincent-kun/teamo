## 5. 已知假设与冲突：接手必须复核

- 当前S1/S2/S3分别为63.2×102.3×39.1、76.4×123.6×47.2、73.2×118.4×45.2mm，均为W×H×D圆角壳讨论占位，不是已验证胶囊尺寸。
- 自研PCB42×55×10、相机24mm安装深度、部分显示屏厚度、声腔及RF隔离是假设；相机MIS5001B不等于目标120–130°FOV已满足。
- S2宽度来源含42mm板＋20mm天线区＋10mm试验隔离＋4mm壁；10mm不是FXP14已确认净空。S3若采用同预算则宽不足。
- 当前投影/深度栈不是完整装配模型。必须查后腔与电池/PCB、USB/SIM、线材及支架的同层干涉；投影相叠不自动判定碰撞或不碰撞。
- 现有3轴黄金比例是展示假设；用户要比例可追溯，不意味着禁止合理的工程取整或每轴强制φ。
- LiPol1100mAh成品包连续1.1A；EEMB HA“最大电流”及P28A裸芯最大电流不能转换为成品包连续保证。
- Adafruit258商品与链接规格书宽度冲突；Adafruit2011旧缺货口径已过时，供货仍需当批重新确认。
- Air780E、Air780ER网络功能不同；SIMCom/Quectel系列区域与固件要锁订货号。
- 喇叭CES B后缀图为系列参考；Adafruit3968图片/功率有版本问题。后腔试验体积不是厂商额定要求。
- 竞品电池资料目录注记是“同规格替代”，不能当作BodyPark原厂电池证据。
