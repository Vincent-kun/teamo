> 本目录包含竞品拆解信息及第三方器件资料，仅用于项目研究与内部评审。对外公开前应检查公司保密要求、图片版权和供应商资料授权范围。

## 使用说明

1. 原始器件资料保留供应商原文件，用于核对关键参数。
2. AI 翻译版本仅作为阅读辅助，关键参数应以供应商原始数据手册为准。
3. BOM、成本和复刻判断属于阶段性研究结论，后续选型变化时应同步更新版本。
4. `.DS_Store` 等系统文件不纳入版本管理。
